## অনেক জোনের এক নাম

আগের লেসনগুলো প্রতিটি একটি করে রেফারেন্স পয়েন্ট নিয়ে ছিল: [Liquidity](/bn/ict/liquidity), [FVG](/bn/ict/fvg), [Order Block](/bn/smc/order-blocks), [Dealing Range](/bn/ict/dealing-range) আর [OTE](/bn/ict/ote)। **PD Array** হলো ICT এর দেওয়া নাম, যেসব দামের রেফারেন্স থেকে ট্রেড করা যায় তাদের সবার জন্য, রেঞ্জে তাদের অবস্থান অনুযায়ী সাজানো।

<Callout type="info" title="সংজ্ঞা">
  **PD Array** (Premium/Discount Array) হলো এমন যেকোনো দামের রেফারেন্স, যেখানে Price রিঅ্যাক্ট করার সম্ভাবনা আছে: Order
  Block, Fair Value Gap, Breaker, Liquidity Pool ইত্যাদি। "PD" মানে Array টি প্রেক্ষাপট মেনে ব্যবহার হয়। **Discount
  Array** Buy এর জন্য, **Premium Array** Sell এর জন্য, আর Price কোন অর্ধেকে আছে তা ঠিক করে Dealing Range।
</Callout>

## PD Array Matrix

![PD Array Matrix — রেঞ্জের প্রান্ত থেকে Equilibrium পর্যন্ত প্রতিটি Array সাধারণত কোথায় থাকে](/images/ict/pd-arrays/pd-array-matrix-dark.png)

ICT রেঞ্জের প্রতিটি দিকে Array গুলো একটি নির্দিষ্ট ক্রমে সাজান:

| # | Premium (Sell এর জন্য)        | Discount (Buy এর জন্য)        |
| - | ----------------------------- | ----------------------------- |
| ১ | Old High / Buy-Side Liquidity | Old Low / Sell-Side Liquidity |
| ২ | Rejection Block               | Rejection Block               |
| ৩ | Bearish Order Block           | Bullish Order Block           |
| ৪ | Bearish FVG (SIBI)            | Bullish FVG (BISI)            |
| ৫ | Liquidity Void                | Liquidity Void                |
| ৬ | Bearish Breaker               | Bullish Breaker               |
| ৭ | Bearish Mitigation Block      | Bullish Mitigation Block      |

**কীভাবে পড়বেন:** ১ নম্বর রেঞ্জের প্রান্তে, ৭ নম্বর Equilibrium এর সবচেয়ে কাছে। এটা বলে Array গুলো সাধারণত **কোথায়** থাকে, কোনটি কতটা নির্ভরযোগ্য তা নয়।

<Callout type="warning" title="সংশোধিত: অবস্থান, র‍্যাংক নয়">
  মূল লেসনে তালিকাটিকে "সবচেয়ে থেকে কম গুরুত্বপূর্ণ" হিসেবে দেখানো হয়েছিল, আর বলা হয়েছিল "OB, FVG এর চেয়ে শক্তিশালী"।
  নির্দিষ্ট শক্তির র‍্যাংকের পক্ষে কোনো তথ্য নেই। এই গাইড Matrix কে রেঞ্জে অবস্থানের ক্রম হিসেবে ব্যবহার করে, আর প্রতিটি
  Array কে তার নিজের মান দিয়ে বিচার করে: Displacement, ফ্রেশ কিনা, আর প্রেক্ষাপট।
</Callout>

## একে একে Array গুলো

| Array                 | কী                                                                         | এন্ট্রির রেফারেন্স                  | লেসন |
| --------------------- | -------------------------------------------------------------------------- | ---------------------------------- | ---- |
| **Old High / Low**    | একটি Swing এক্সট্রিম, যার বাইরে Stop জমে আছে                                | Sweep এর বিপরীতে (MSS সহ)          | [Liquidity](/bn/ict/liquidity) |
| **Rejection Block**   | প্রত্যাখ্যাত একটি Swing এক্সট্রিমের Wick                                    | Wick এর বডির প্রান্ত               | — |
| **Order Block**       | Displacement এর আগের শেষ বিপরীত (Down-Close / Up-Close) ক্যান্ডেল          | Proximal প্রান্ত বা বডির ৫০%       | [Order Block](/bn/smc/order-blocks) |
| **FVG**               | তিন ক্যান্ডেলের Gap; BISI Bullish, SIBI Bearish                            | CE (৫০%)                           | [FVG](/bn/ict/fvg) |
| **Liquidity Void**    | একমুখী লম্বা একটি ক্যান্ডেল বা ক্যান্ডেলের সারি, প্রায় কোনো Overlap নেই    | Void এ ফিরে পূরণ                   | [Imbalance](/bn/smc/imbalance) |
| **Breaker Block**     | যে Order Block **Liquidity নিয়েছে**, তারপর ব্যর্থ হয়েছে                   | রিটেস্টে এর প্রান্ত                 | [Breaker Block](/bn/smc/breaker-blocks) |
| **Mitigation Block**  | যে Order Block **Liquidity নিতে পারেনি**, তারপর ব্যর্থ হয়েছে                | রিটেস্টে এর প্রান্ত                 | [Mitigation Block](/bn/smc/mitigation-blocks) |

## Breaker বনাম Mitigation Block

![Breaker নাকি Mitigation Block — আগের Low একইভাবে ভাঙে; পার্থক্য হলো আগের High আগে নেওয়া হয়েছিল কিনা](/images/ict/pd-arrays/breaker-vs-mitigation-dark.png)

দুটোই ব্যর্থ Order Block, যা উল্টো ভূমিকায় চলে যায়। পার্থক্য হলো ব্যর্থতার **আগে** কী ঘটেছিল:

| Bearish উদাহরণ   | **Breaker Block**                                     | **Mitigation Block**                                     |
| ---------------- | ----------------------------------------------------- | -------------------------------------------------------- |
| ভাঙার আগে        | Price **আগের High এর উপরে** যায় (Liquidity নেয়)       | Price আগের High এ **পৌঁছাতে পারে না**                    |
| জোন              | সেই Move এর Up-Close ক্যান্ডেল                         | সেই দুর্বল র‍্যালির Up-Close ক্যান্ডেল                    |
| তারপর            | একটি Displacement আগের Low ভাঙে                        | একটি Displacement আগের Low ভাঙে                          |
| ট্রেড            | জোনের রিটেস্টে Sell                                    | জোনের রিটেস্টে Sell                                      |
| কেন কাজ করে      | নতুন High এর পেছনে কেনা Buyer রা আটকে যায়             | দুর্বল High এ কেনা Buyer রা লসে পড়ে থাকে                 |

Bullish সংস্করণগুলো ঠিক উল্টো।

<Callout type="warning" title="সংশোধিত সংজ্ঞা">
  মূল লেসনে Mitigation Block কে বলা হয়েছিল "আংশিক পূরণ হওয়া OB" আর তার না-পূরণ হওয়া অংশ। সেটা Mitigated Order Block এর
  বর্ণনা, ICT এর Mitigation Block নয়। এই গাইড উপরের প্রচলিত সংজ্ঞা ব্যবহার করে, যেটা [Order Block](/bn/smc/order-blocks)
  গাইডেও ব্যবহার করা হয়েছে।
</Callout>

## Array বেছে নেওয়া

1. **আগে Higher Timeframe।** একটি Daily Array একটি 15m Array এর চেয়ে বেশি গুরুত্বপূর্ণ। Higher Timeframe Array এর **ভেতরে** থাকা লোয়ার টাইমফ্রেম Array খুঁজুন।
2. **রেঞ্জের সঠিক অর্ধেক।** Buy এর জন্য Discount Array, Sell এর জন্য Premium Array। ভুল অর্ধেকে থাকা Array অপেক্ষার কারণ।
3. **কাছেরটা আগে।** Price সাধারণত সবচেয়ে কাছের Array এ আগে পৌঁছায়। পছন্দের Array তে সরাসরি না গিয়ে সেটার জন্য পরিকল্পনা করুন।
4. **মান।** Displacement সহ, Kill Zone এ তৈরি, আর এখনো ফেরা হয়নি এমন Array বেছে নিন।
5. **স্তূপ।** দুই-তিনটি Array এক দামে মিললে সেই দাম বেশি স্পষ্ট। মেলার জায়গা এন্ট্রিকে সরু করে, আর রিঅ্যাকশনের পক্ষে বেশি কারণ দেয়।

<Callout type="info" title="এই উদাহরণ সম্পর্কে">

  রেকর্ড নয়। R:R হলো পরিকল্পিত রিস্ক-রিওয়ার্ড, ফলাফল নয়।

**প্রেক্ষাপট:** Daily চার্ট Discount এ, Bias Bullish।

**পর্যবেক্ষণ**

1. **Sweep:** দুপুর ১২:১৫ BD তে, London Kill Zone এ, Price **1.0838** এর নিচের Sell Stop নেয়, **1.0833** পর্যন্ত Wick করে।
2. **MSS:** ২৩ পিপের Displacement (গড় ৬ পিপ) **1.0868** Lower High এর উপরে ক্লোজ করে।
3. **এক দামে তিনটি Array:**
   - **Bullish Order Block:** Move এর আগের শেষ Down-Close ক্যান্ডেল, 1.0845 – 1.0859, যার ৫০% **1.0852**।
   - **Bullish FVG:** **1.0848 – 1.0856**, Displacement এর রেখে যাওয়া।
   - **OTE:** 1.0833 → 1.0892 Leg এর ৬২–৭৯% হলো **1.0855 – 1.0845**।
4. **এন্ট্রি:** **দুপুর ২:৩০ BD** তে প্রথম ফেরা **1.0852** এ পৌঁছায়, তিনটিরই ভেতরে। Buy।

| লেভেল     | প্রাইস  | যুক্তি                                     |
| --------- | ------- | ------------------------------------------ |
| এন্ট্রি    | 1.0852  | OB ৫০% + FVG + OTE                          |
| Stop      | 1.0840  | তিনটি Array এর নিচে                         |
| টার্গেট    | 1.0920  | Buy-Side Liquidity                         |
| রিস্ক      | ১২ পিপ  | 1.0852 − 1.0840                            |
| রিওয়ার্ড   | ৬৮ পিপ  | 1.0920 − 1.0852                            |
| **R:R**   | **১ : ৫.৭** | ৬৮ ÷ ১২                                |

**Invalidation:** 15m ক্যান্ডেল 1.0845 এর নিচে ক্লোজ করলে, যা তিনটি Array এরই তলা।

**Stop এর সিদ্ধান্ত:** 1.0840 এর Stop তিনটি Array এর নিচে, কিন্তু **Leg এর 1.0833 Low এর উপরে**। [OTE](/bn/ict/ote) লেসনে Stop রাখা হয় Leg এর শুরুর বাইরে, এখানে প্রায় 1.0830: রিস্ক ২২ পিপ আর **R:R ১ : ৩.১**। ছোট Stop বেশি R:R দেয়, কিন্তু Structure না ভেঙেই গভীর একটি পুলব্যাকে হিট হতে পারে। সেটআপ আসার আগেই ঠিক করুন কোন নিয়ম ব্যবহার করবেন।

## অনুশীলন

1. একটি 4H চার্টে Dealing Range আঁকুন। Premium আর Discount এর প্রতিটি Array মার্ক করুন, আর Matrix অনুযায়ী নম্বর দিন।
2. 15m চার্টে এমন সেটআপ খুঁজুন যেখানে দুই বা তার বেশি Array মিলেছে। মেলার জায়গা কতটা চওড়া আর Price কীভাবে রিঅ্যাক্ট করল লিখুন।
3. পাঁচটি ব্যর্থ Order Block খুঁজে প্রতিটিকে Breaker বা Mitigation Block হিসেবে ভাগ করুন। রিটেস্টে কী হলো দেখুন।
4. ফলাফল আপনার [ট্রেডিং জার্নালে](/bn/tools/journal-template) লিখুন।

## প্রশ্ন ও উত্তর

### Order Block কি FVG এর চেয়ে শক্তিশালী?

নির্দিষ্ট কোনো র‍্যাংকের পক্ষে নির্ভরযোগ্য প্রমাণ নেই। দুটোই সবচেয়ে ভালো কাজ করে Displacement, ফ্রেশনেস আর রেঞ্জের সঠিক অর্ধেকে।

### সব Array কি লাগবে?

না। বেশিরভাগ Trader দুই-তিনটি ভালোভাবে ব্যবহার করেন: সাধারণত Order Block, FVG আর Liquidity। বাকিগুলো চিনে রাখার জন্য শিখুন।

### দুটো Array একে অপরের বিপরীতে থাকলে?

আপনার Discount এন্ট্রির ঠিক উপরে একটি Premium Array থাকলে সেটাই প্রথম বাধা। সেখানে আংশিক প্রফিট নিন বা অন্য ট্রেড বেছে নিন।
