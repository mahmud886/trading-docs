## সূত্র

**Expectancy** হলো একটি ট্রেডের গড় ফল, **R** এ (ঝুঁকির পরিমাণের গুণিতক) মাপা:

> **Expectancy = (জয়ের হার × গড় জয়) − (হারের হার × গড় হার)**

আপনি সবসময় ১R ঝুঁকি নিলে এবং টার্গেট ঝুঁকির *RR* গুণ হলে এটি সরল হয় **W × RR − (১ − W)**, যেখানে *W* জয়ের হার। ধনাত্মক মানে গড় ট্রেড **খরচের আগে** অর্থ আয় করে; শূন্য মানে Break-even।

<Callout type="warning" title="সংশোধিত ও নরম করা হয়েছে">
  মূল লেসনে Expectancy কে "প্রতিটি লাভজনক সিস্টেমের গাণিতিক ভিত্তি" বলা হয়েছিল এবং "১০০+ ট্রেড" নমুনাকে যথেষ্ট ধরা হয়েছিল। Expectancy কাজের সারাংশ, কিন্তু এটি একটি **অনুমান**, আর ছোট নমুনার ধনাত্মক অনুমান সহজেই ভাগ্য হতে পারে। এই লেসনে এর ওপর একটি মোটামুটি ত্রুটি-সীমা বসানো দেখানো হয়েছে।
</Callout>

## Break-Even জয়ের হার

Expectancy শূন্য হয় যখন **W = ১ / (১ + RR)**।

| Reward-to-risk | Break-even জয়ের হার | +০.২৫R এর জন্য জয়ের হার |
| -------------- | ------------------- | ------------------- |
| ১ : ১          | ৫০%                 | ৬২.৫%               |
| ১ : ১.৫        | ৪০%                 | ৫০%                 |
| ১ : ২          | ৩৩.৩%               | ৪১.৭%               |
| ১ : ৩          | ২৫%                 | ৩১.৩%               |

(+০.২৫R এর জন্য জয়ের হার: W = (০.২৫ + ১) / (RR + ১)।) উচ্চ Reward-to-risk আপনার প্রয়োজনীয় জয়ের হার কমায়, কিন্তু সেটি তবুও অর্জন করতে হবে।

## ৪০-ট্রেডের একটি নমুনা

![উপরে: Reward-to-risk ১:১, ১:১.৫, ১:২ ও ১:৩ এর জন্য জয়ের হারের বিপরীতে প্রতি ট্রেডের Expectancy, Break-even জয়ের হার ৫০%, ৪০%, ৩৩.৩% ও ২৫%। নিচে: একটি সিন্থেটিক ৪০-ট্রেডের নমুনা — ৪২% জয় +২R এ, গড় হার ০.৯৫R, Expectancy +০.৩৮R এবং প্রায় ৯৫% ব্যবধান −০.০৭R থেকে +০.৮২R](/images/quantitative/expectancy-formula/expectancy-formula-dark.png)

<Callout type="info" title="এই চার্ট সম্পর্কে">
  ৪০টি ট্রেড **সিন্থেটিক**, +২R জয়ের প্রায় ৪২% সম্ভাবনায় এলোমেলোভাবে তোলা। ব্যবধানে সরল নরমাল আনুমানিকতা (গড় ± ১.৯৬ Standard Error) ব্যবহার হয়েছে, যা ছোট নমুনায় মোটামুটি।
</Callout>

| পরিমাণ                 | নমুনায় মান                                       |
| ------------------------ | --------------------------------------------------------- |
| ট্রেড                   | ৪০ (১৭ জয়, ২০ হার, ৩ Break-even বা আংশিক)       |
| জয়ের হার                 | ১৭ ÷ ৪০ = ৪২.৫%                                           |
| গড় জয়              | +২.০০R                                                    |
| গড় হার             | −০.৯৫R                                                    |
| **Expectancy**           | ০.৪২৫ × ২.০০ − ০.৫০ × ০.৯৫ = **+০.৩৭৫R** (≈ +০.৩৮R)       |
| R এর Standard Deviation  | ১.৪৪R                                                     |
| Standard Error           | ১.৪৪ ÷ √৪০ = ০.২৩R                                        |
| **প্রায় ৯৫% ব্যবধান** | **−০.০৭R থেকে +০.৮২R**                                      |

গড় ধনাত্মক, কিন্তু ব্যবধানে **শূন্য আছে**: মাত্র ৪০ ট্রেডে এই নমুনা আসল Edge আর ভাগ্য আলাদা করতে পারে না। অনিশ্চয়তা নমুনার আকারের বর্গমূল অনুযায়ী কমে: ব্যবধান অর্ধেক করতে প্রায় চার গুণ ট্রেড লাগে।

## খরচ

খরচ জয় ও হার দুই ধরনের ট্রেডই কমায়। R এ: **R এ খরচ = পিপে খরচ ÷ পিপে Stop দূরত্ব**।

### উদাহরণ (চার্ট ছাড়া) — খরচসহ পরিকল্পনা

এন্ট্রি **1.0850**, Stop **1.0830** (২০ পিপ), টার্গেট **1.0890** (৪০ পিপ): পরিকল্পিত **১ : ২.০**। ৪০% জেতার আশা করলে খরচের আগে Expectancy ০.৪ × ২ − ০.৬ = **+০.২০R**। ১.৫ পিপ রাউন্ড-ট্রিপ খরচ প্রতি ট্রেডে ১.৫ ÷ ২০ = ০.০৭৫R, তাই খরচের পর Expectancy প্রায় **+০.১২৫R**। ৩৫% জয়ের হারে খরচের আগে ০.৩৫ × ২ − ০.৬৫ = +০.০৫R আর পরে **−০.০২৫R**: খরচ এটিকে ঋণাত্মক করে।

| ------------------------------------------------- | ---------------------------------------------------------- |
| খরচ উপেক্ষা                                    | প্রতি ট্রেড থেকে R এ খরচ বাদ দিন                        |
| অনিশ্চয়তা ছাড়া Expectancy জানানো          | ব্যবধান বা Standard Error দিন                        |
| ভিন্ন ঝুঁকির আকার মেশানো                       | আগে প্রতিটি ফল R এ রূপান্তর করুন                            |
| শুধু জয়ের হার ব্যবহার                              | গড় জয় ও হার ছাড়া জয়ের হারের অর্থ কম     |
| নিয়ম বদলে আবার অনুমান                    | প্রতিটি নিয়ম বদলকে নতুন নমুনা ধরুন                       |

## অনুশীলন

1. আপনার শেষ ৩০ ট্রেড R এ রূপান্তর করুন (ফল ÷ ঝুঁকির পরিমাণ)।
2. জয়ের হার, গড় জয়, গড় হার ও Expectancy হিসাব করুন; তারপর Standard Error ও মোটামুটি ৯৫% ব্যবধান।
3. R এ আপনার সাধারণ খরচ বাদ দিন। ব্যবধান কি এখনো শূন্যের উপরে?
4. আপনার [ট্রেডিং জার্নালে](/bn/tools/journal-template) লিখুন।
