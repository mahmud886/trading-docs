## Equity Curve Management কী?

**Equity Curve Management** আপনার নিজের Equity কার্ভ কেমন আচরণ করছে তার ভিত্তিতে আপনি কতটা ট্রেড করবেন — বা করবেন কি না — তা সমন্বয় করে। প্রচলিত রূপ:

| কৌশল                    | নিয়ম (উদাহরণ)                                                                | লক্ষ্য                                            |
| ---------------------------- | ----------------------------------------------------------------------------- | ---------------------------------------------- |
| **Equity-curve ফিল্টার**      | Equity কার্ভ তার N-ট্রেড Moving average এর উপরে থাকলেই ট্রেড          | খারাপ সময়ে ট্রেড করা থামানো             |
| **Drawdown স্কেলিং**         | Drawdown সীমা ছাড়ালে প্রতি ট্রেডের ঝুঁকি অর্ধেক                    | ক্ষতি ধীর করা                                |
| **বিরতির নিয়ম**               | X Drawdown এ রিভিউ শেষ না হওয়া পর্যন্ত ট্রেড বন্ধ                      | Edge এখনো আছে কি না যাচাইয়ে বাধ্য করা       |
| **স্কেল আপ**               | কার্ভ নতুন High করলে ঝুঁকি সামান্য বাড়ানো                             | যে Edge কাজ করছে মনে হয় তাতে জোর দেওয়া         |

<Callout type="warning" title="সংশোধিত ও নরম করা হয়েছে">
  মূল লেসনে স্থির নিয়ম ("১ SD এর বেশি হলে সাইজ কমান", "২ SD এর বেশি হলে বিরতি") মান হিসেবে দেওয়া হয়েছিল। এগুলো পছন্দ, আইন নয়, আর এর প্রমাণ মিশ্র। Equity-curve নিয়ম Drawdown কমাতে পারে, কিন্তু Edge তৈরি করে না, আর পুনরুদ্ধার বাদ দিতে পারে। এই লেসন দুটি প্রভাবই মাপে।
</Callout>

## একটি কাজের উদাহরণ: ক্ষয়ে যাওয়া Edge

সিস্টেমটি ৩০০ ট্রেড নেয়, জয় +১.৫R, হার −১R। জয়ের হার ট্রেড ১–১০০ এ **৫০%**, ১০১–২০০ এ **৩৩%** (ঋণাত্মক Expectancy: ০.৩৩ × ১.৫ − ০.৬৭ = −০.১৭R), আর ২০১–৩০০ এ আবার **৫০%**। ফিল্টার নিয়ম: **সব সংকেতের** Equity কার্ভ তার **২০-ট্রেড Moving average** এর উপরে থাকলেই পরের ট্রেড নিন; বাদ দেওয়া ট্রেডও ওই "ভার্চুয়াল" কার্ভ আপডেট করে।

![উপরে: ৩০০-ট্রেডের একটি সিন্থেটিক সিস্টেমের সব সংকেতের Equity কার্ভ, যার জয়ের হার ১০১–২০০ ট্রেডে ৫০% থেকে ৩৩% এ নেমে আবার ৫০% এ ফেরে, ২০-ট্রেড Moving average ও ফিল্টার পরের ট্রেড বাদ দেয় এমন ছায়াময় অংশসহ। নিচে: ফিল্টারসহ (+১৯R, সর্বোচ্চ Drawdown ১৬R, ৩০০ এর ১৫৬ ট্রেড) বনাম সবসময় ট্রেডে (+১২R, সর্বোচ্চ Drawdown ২৪R) সঞ্চিত R](/images/quantitative/equity-curve-management/equity-curve-filter-dark.png)

  ট্রেডগুলো **সিন্থেটিক**: তিন জয়ের-হার পর্ব থেকে একটি এলোমেলো ক্রম। এই ক্রমটি অনেকের একটি (নিচের ১,০০০-ক্রমের ফল দেখুন)।

| পরিমাপ                    | সবসময় ট্রেড | ফিল্টারসহ |
| -------------------------- | ------------ | --------------- |
| নেওয়া ট্রেড               | ৩০০          | ১৫৬             |
| চূড়ান্ত ফল               | +১২.৫R       | +১৯R            |
| সর্বোচ্চ Drawdown           | ২৩.৫R        | ১৫.৫R           |
| দুর্বল পর্বে ফল (১০১–২০০) | প্রায় −১৮R | ফিল্টার বেশিরভাগ বাদ দেয়: ১০০ এর ২২ ট্রেড নেওয়া |

এই ক্রমে ফিল্টার দুর্বল পর্বের ১০০ ট্রেডের ৭৮টি বাদ দিয়ে এগিয়ে শেষ করেছে। এটি প্রশংসনীয় ক্ষেত্র। একই সিস্টেম ও নিয়ম **১,০০০** এলোমেলো ক্রমে দেয়:

| ১,০০০ সিমুলেটেড ক্রমে                    | ফল  |
| ------------------------------------------------- | ------- |
| ফিল্টার সর্বোচ্চ Drawdown কমিয়েছে           | ৯২%     |
| ফিল্টার চূড়ান্ত ফল বেশি দিয়েছে             | ৫০%     |
| সর্বোচ্চ Drawdown এর গড় কমতি             | ১৩.৭R   |
| চূড়ান্ত ফলের গড় পার্থক্য                | +১.৩R   |

তাই নির্ভরযোগ্য প্রভাব **ছোট Drawdown**। লাভের ওপর প্রভাব কয়েন-ছোড়ার কাছাকাছি: Edge সত্যিই ক্ষয়ে গেলে ফিল্টার সাহায্য করে; Drawdown শুধু নয়েজ হলে এটি **পুনরুদ্ধার বাদ দেয়** আর অর্থ খরচ করে।

## নিয়ম বাছা ও পরীক্ষা

| প্যারামিটার / পছন্দ            | বিবেচনা                                                                   |
| ----------------------------- | ------------------------------------------------------------------------------- |
| গড়ের উইন্ডো               | ছোট = অস্থির, অনেক বাদ দেয়; লম্বা = প্রতিক্রিয়ায় ধীর                        |
| ভার্চুয়াল কার্ভ ব্যবহার       | বাদ দেওয়া ট্রেডও ট্র্যাক করতে হবে যাতে ফিল্টার আবার চালু হতে পারে            |
| পুনঃপ্রবেশ নিয়ম               | ঠিক কখন ফিরবেন তা সংজ্ঞায়িত করুন                                                  |
| Out-of-sample পরীক্ষা            | নিয়মটির নিজস্ব প্যারামিটার আছে — [Backtesting](/bn/quantitative/backtesting-methodology) দেখুন |

### উদাহরণ (চার্ট ছাড়া) — ঝুঁকি-স্কেলিং নিয়ম

নিয়ম: স্বাভাবিক ঝুঁকি প্রতি ট্রেডে **১%**; Equity কার্ভ শীর্ষ থেকে **১০R এর বেশি** নিচে থাকলে **০.৫%**; নতুন শীর্ষে ১% এ ফিরুন। এন্ট্রি **1.0850**, Stop **1.0830** (২০ পিপ), টার্গেট **1.0880** (পরিকল্পিত **১ : ১.৫**): Drawdown এ একই ট্রেড অর্ধেক ঝুঁকিতে সাইজ হয় (১০,০০০ অ্যাকাউন্টে ১০০ এর বদলে ৫০, মানে প্রতি পিপে ৫ এর বদলে ২.৫)। Edge ফিরলে খরচ ধীর পুনরুদ্ধার; চলে গেলে সাশ্রয় পরবর্তী ক্ষতির প্রায় অর্ধেক।

| ভুল                                         | সমাধান                                                     |
| ----------------------------------------------- | ---------------------------------------------------------- |
| ট্রেড থামলে ট্র্যাকিং থামানো         | প্রতিটি সংকেত ট্র্যাক করুন যাতে নিয়ম আবার চালু হতে পারে                  |
| ফিল্টার লাভ বাড়ায় ধরে নেওয়া                   | মূলত Drawdown ছাঁটে; লাভের প্রভাব পরীক্ষা করুন           |
| একই ডেটায় উইন্ডো টিউন                    | Out-of-sample ও অনেক ক্রমে পরীক্ষা করুন               |
| Drawdown এর মাঝে নিয়ম বদলানো                     | আগে নিয়ম ঠিক করুন                                    |
| বিরতিকে রায় ধরা                    | বিরতি রিভিউয়ের বিন্দু, Edge চলে গেছে তার প্রমাণ নয়      |

## অনুশীলন

1. আপনার শেষ ১০০ ট্রেড R এ Equity কার্ভ হিসেবে ২০-ট্রেড গড়সহ চার্ট করুন। কত ঘন কার্ভ গড়ের নিচে?
2. ফিল্টার নিয়ম আপনার ইতিহাসে প্রয়োগ করুন: কতগুলো ট্রেড বাদ যেত, আর সেগুলোর R কত ছিল?
3. আপনার ট্রেড তালিকা এলোমেলো ক্রমে ১,০০০ বার সিমুলেট করে নিয়মসহ ও নিয়ম ছাড়া Drawdown ও চূড়ান্ত ফল তুলনা করুন।
4. আপনার [ট্রেডিং জার্নালে](/bn/tools/journal-template) লিখুন।
