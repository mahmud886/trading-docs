## DOM কী?

**Depth of Market (DOM)** — **Level 2**, **Order Book** বা **Ladder** ও বলা হয় — প্রতিটি প্রাইসে অপেক্ষমাণ **Limit অর্ডার** তালিকাভুক্ত করে: মার্কেটের নিচে Bid (Buy Limit) আর উপরে Ask (Sell Limit)।

| লেভেল       | কী দেখায়                                           |
| ---------- | -------------------------------------------------- |
| **Level 1** | সেরা Bid, সেরা Ask, শেষ প্রাইস                      |
| **Level 2** | প্রতিটি পাশে কয়েকটি প্রাইসে অপেক্ষমাণ অর্ডার          |

DOM দেখায় কী **অপেক্ষমাণ**; **Tape** (Time and Sales) দেখায় কী **এক্সিকিউটেড**। দুটোই লাগে: অপেক্ষমাণ অর্ডার ট্রেড নয়, আর যেকোনো সময় সরানো যায়।

<Callout type="warning" title="সুর নরম করা হয়েছে">
  মূল লেসনে DOM কে "প্রাতিষ্ঠানিক উদ্দেশ্য দেখার সবচেয়ে কাছের জিনিস" বলা হয়েছিল। অপেক্ষমাণ অর্ডার দেখায় কেউ এখন কী করতে **ইচ্ছুক**, কী করবে নয়,
  আর মিলিসেকেন্ডে বাতিল করা যায়। বড় অংশগ্রহণকারীরা প্রায়ই সাইজ লুকায়। DOM কে *অফারের স্ন্যাপশট* হিসেবে পড়ুন, উদ্দেশ্য হিসেবে নয়।
</Callout>

শিক্ষাটা "ওয়াল মানেই Resistance" নয়। শিক্ষা হলো **ওয়াল একটি অনুমান**: এতে ট্রেড করা হলে যদি টিকে থাকে তবেই গুরুত্ব। Consume হলে এর পেছনের বুকই ঠিক করে প্রাইস কত দ্রুত নড়বে।

## কী দেখবেন

| পর্যবেক্ষণ               | সম্ভাব্য পাঠ                                              | সতর্কতা                                       |
| ----------------------- | --------------------------------------------------------- | --------------------------------------------- |
| **মোটা লেভেল**           | সম্ভাব্য Support বা Resistance                             | অদৃশ্য হতে বা লুকানো থাকতে পারে                |
| **পাতলা লেভেল**          | প্রাইস দ্রুত ভেদ করতে পারে                                  | পাতলা বুক নিউজেও Gap করে                       |
| **অর্ডার আবার ভরছে**       | কেউ একই প্রাইসে রিলোড করছে                                 | দেখুন [Iceberg and Spoofing](/bn/order-flow/iceberg-spoofing) |
| **Hit হওয়ার আগে অর্ডার উধাও** | অনেক কারণে বাতিল হতে পারে, Spoofing সহ                      | ম্যানিপুলেশন ধরে নেবেন না                       |
| **Bid/Ask Imbalance**   | এক পাশ এখন ভারী                                           | Imbalance ক্রমাগত বদলায়; Tape দেখুন             |

### DOM এ Absorption

**Absorbing** লেভেল প্রাইস ভেদ না করে Aggressive Volume নেয়: Tape এ এক প্রাইসে অনেক কন্ট্রাক্ট এক্সিকিউট হয় যখন দেখানো সাইজ প্রায় একই থাকে বা আবার ভরে। চার্টে ৩২০ কন্ট্রাক্ট ওয়ালে আঘাত করেছে আর প্রাইস আটকেছে — ওয়ালের বাকিটা সরে যাওয়া পর্যন্ত।

### উদাহরণ (চার্ট ছাড়া) — DOM কে একটি ইনপুট হিসেবে ব্যবহার

প্রাইস র‍্যালি করে **1.0954** এ গিয়ে **1.0955** এর Ask ওয়ালে ঠেকে। "ওয়াল আছে" বলে Sell না করে পরিকল্পনা: *যদি* ওয়াল Consume হয় (সাইজ ১০০ এর নিচে নামে আর ক্রেতারা তখনো Lift করছে) আর প্রাইস **1.0956** এ ট্রেড করে, তবে **1.0957** এ Buy, Stop **1.0951** (শেষ Bid ক্লাস্টারের নিচে), টার্গেট **1.0975**: রিস্ক ৬, রিওয়ার্ড ১৮, পরিকল্পিত **১ : ৩.০**। উল্টে ওয়াল টিকে গিয়ে Tape এ ক্রেতা শুকিয়ে গেলে কোনো ট্রেড নেই।

## বিভিন্ন মার্কেটে DOM

| মার্কেট                  | DOM কী দেখায়                                                         |
| ----------------------- | -------------------------------------------------------------------- |
| ফিউচার্স (যেমন 6E)       | একটি এক্সচেঞ্জের কেন্দ্রীয় Limit Order Book — পূর্ণ অপেক্ষমাণ গভীরতা     |
| স্টক                    | একটি ভেন্যুর বুক; আরও কয়েকটি একই স্টক ট্রেড করে                        |
| **Spot ফরেক্স**          | কেন্দ্রীয় বুক নেই: ব্রোকারের DOM শুধু নিজের Liquidity Provider বা ক্লায়েন্ট দেখায় |

অর্ডার-বুকের তথ্য চাওয়া Spot-ফরেক্স ট্রেডাররা প্রায়ই **ফিউচার্স** বুককে প্রক্সি হিসেবে ব্যবহার করেন।

## সাধারণ ভুল

| ভুল                                            | সমাধান                                                 |
| ---------------------------------------------- | ------------------------------------------------------ |
| ওয়ালকে নিশ্চয়তা ধরে ট্রেড                        | ট্রেড হলে এটা কেমন আচরণ করে দেখার অপেক্ষা করুন              |
| Tape উপেক্ষা                                    | বুকের পাশে এক্সিকিউটেড Volume দেখুন                      |
| উধাও হওয়া প্রতিটি অর্ডারকে "Spoofing" বলা          | বাতিল স্বাভাবিক; পুনরাবৃত্ত প্যাটার্ন খুঁজুন                 |
| Spot ফরেক্সে ব্রোকারের "DOM" কে আসল বুকের মতো ব্যবহার | এটা কোন Liquidity প্রতিনিধিত্ব করে তা জানুন              |
| Stop ছাড়া DOM Scalping                         | আগে সাইজ আর Stop; গতি পরে                               |

## অনুশীলন

1. একটি ফিউচার্স DOM এ (বা রিপ্লেতে) ১০ মিনিট একটি বড় অপেক্ষমাণ অর্ডার দেখুন। এটা কি টিকে, রিফিল হয়, উধাও হয়, নাকি Consume হয়?
2. ওই সময়ে ওই প্রাইসে Tape এর ট্রেড Volume লিখুন।
3. ওয়াল বদলানোর পর প্রাইস কী করেছে লিখুন।
4. আপনার [ট্রেডিং জার্নালে](/bn/tools/journal-template) লিখুন।
