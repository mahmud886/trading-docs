## What is an FVG? (Fair Value Gap)

An **FVG** is a price zone where fast displacement created inefficiency.

In simple terms: Price moved so fast that buyers and sellers didn't get fully matched.

### Bullish FVG Requirements:
```
Candle 1:  Close = 1.0900
Candle 2:  (strong buying)
Candle 3:  Open = 1.0920

Condition: Candle 1's High < Candle 3's Low
```

**On Chart:**
```
1.0930 ┐
1.0920 ├─ ← Candle 3 Open (gap up)
1.0910 │     ↑ This gap = FVG
1.0900 ├─ ← Candle 1 Close
```

### Bearish FVG Requirements:
```
Candle 1:  Close = 1.0900
Candle 2:  (strong selling)
Candle 3:  Open = 1.0880

Condition: Candle 1's Low > Candle 3's High
```

**On Chart:**
```
1.0900 ├─ ← Candle 1 Close
1.0890 │     ↓ This gap = FVG
       ├─ ← Candle 3 Open (gap down)
1.0880 ┘
```

<Callout type="tip" title="FVG Behavior">
Price treats FVGs like "magnets"—it returns to rebalance the efficiency gap.
</Callout>

## What is an Order Block?

An **Order Block** is the candle where institutional traders loaded major positions.

### Bullish Order Block:
```
Strong candle during upward move
↓
Sellers try to break it
↓
Fail and bounce back up

This candle = Bullish Order Block
```

### Bearish Order Block:
```
Strong candle during downward move
↓
Buyers try to push it higher
↓
Fail and reverse back down

This candle = Bearish Order Block
```

## Complete Entry Setup

### Pre-Check:
1. **High timeframe trend** (4H or Daily) = Uptrend
2. **Swing Structure** = Making higher highs and higher lows
3. **Any CHOCH yet?** = No, still bullish

### Finding Entry Zone:
1. **Identify Order Block** = That strong buy candle
2. **Find FVG** = Gap inside or near Order Block
3. **Multiple confluences?** = 2+ levels confirmed

### Entry Rules:
```
When price enters FVG:
↓
Watch for bullish candle formation
↓
Candle Close above Order Block
↓
ENTER - Place stop below Bullish OB
```

## FVG & Order Block Failures

### When FVG is Never Hit:
```
Likely causes:
1. Countertrend on higher timeframe
2. Major news release
3. Order Block wasn't actually strong
→ Skip entry—wait for next opportunity
```

### When Signal Was Wrong:
```
Avoid:
1. Trend reversed exactly before entry
2. Confluence was only one level
3. Near round numbers = high noise
```
