## What is OTE (Optimal Trade Entry)?

The **Optimal Trade Entry (OTE)** is an ICT concept that identifies the highest-probability entry zone within a retracement. It sits between the **61.8% and 78.6% Fibonacci retracement levels** — the sweet spot where institutional orders cluster.

<Callout type="info" title="Why OTE Works">
When price retraces after an impulsive move, institutions place their orders in the 61.8-78.6% zone. This zone offers the best balance between:
- **Confirmation** (price has retraced enough to show the pullback is real)
- **Risk** (stop loss is still tight — beyond the 100% level)
- **Reward** (you're entering deep enough for excellent R:R)
</Callout>

## Fibonacci Retracement Basics

### Key Fibonacci Levels:

| Level | Name | Significance |
|-------|------|-------------|
| 0% | Swing extreme | Start of retracement |
| 23.6% | Shallow | Too shallow for entry |
| 38.2% | Standard | Minimum retracement |
| 50% | Equilibrium | Fair value / midpoint |
| 61.8% | Golden Ratio | **OTE zone starts** |
| 70.5% | ICT Sweet Spot | **Prime OTE level** |
| 78.6% | Deep | **OTE zone ends** |
| 100% | Full retrace | Invalidation level |

### How to Draw Fibonacci:

**For Bullish OTE (buying the pullback in an uptrend):**
- Draw from the **swing LOW** to the **swing HIGH**
- The 61.8-78.6% zone between them = OTE (buy zone)

**For Bearish OTE (selling the pullback in a downtrend):**
- Draw from the **swing HIGH** to the **swing LOW**
- The 61.8-78.6% zone between them = OTE (sell zone)

```
Bullish OTE Example:

Swing High ─── 1.0900 (0%)
│
│  23.6% ──── 1.0876
│  38.2% ──── 1.0857
│  50.0% ──── 1.0840
│  ┌─────────────────────────┐
│  │ 61.8% ──── 1.0823      │
│  │ 70.5% ──── 1.0810      │  ← OTE ZONE (Buy here)
│  │ 78.6% ──── 1.0796      │
│  └─────────────────────────┘
│  100% ───── 1.0780 (Invalidation)
│
Swing Low ──── 1.0780 (100%)
```

## OTE + Order Block = Maximum Confluence

The most powerful ICT setup is when an **Order Block sits within the OTE zone**:

1. Price makes an impulsive move (expansion leg)
2. Within that leg, identify the OB (last opposing candle before displacement)
3. Draw Fibonacci from swing low to swing high
4. If the OB falls within 61.8-78.6% retracement → **Maximum confluence**

```
This OB-in-OTE setup gives you:
✓ Institutional order flow backing (OB)
✓ Mathematical probability (Fibonacci)
✓ Optimal risk placement (stop below OTE)
✓ Excellent R:R (entering deep in the retracement)
```

## The Complete OTE Trading Strategy

### Step-by-Step Process:

1. **Identify HTF Trend Direction** (Daily/4H making HH/HL or LH/LL)
2. **Wait for an Expansion Leg** (impulsive move in trend direction with displacement)
3. **Draw Fibonacci** on the expansion leg
4. **Mark the OTE Zone** (61.8-78.6%)
5. **Look for Confluence in OTE:**
   - Order Block within OTE? ✓
   - FVG within OTE? ✓
   - Previous structure level in OTE? ✓
6. **Wait for Price to Retrace** into the OTE zone
7. **Enter with LTF Confirmation** (15M/5M CHOCH at OTE)
8. **Stop Loss:** Beyond the 100% level (full swing)
9. **Target:** -27% or -62% Fibonacci extension (expansion targets)

## Fibonacci Extensions for Targets

Once you enter at OTE, use Fibonacci extensions for targets:

| Extension Level | Use Case |
|----------------|----------|
| -27% (1.272) | **Conservative target** — first TP |
| -62% (1.618) | **Standard target** — main TP |
| -100% (2.0) | **Aggressive target** — let runners go here |
| -162% (2.618) | **Extreme target** — rare but powerful |

### Target Placement:

For a bullish trade entered at OTE:
```
Target 3 ─── -100% extension (2.0)
Target 2 ─── -62% extension (1.618)  ← Main TP
Target 1 ─── -27% extension (1.272)  ← Partial TP

Entry ────── 70.5% retracement (OTE)
Stop ─────── Below 100% (full swing low)
```

## OTE Invalidation Rules

Your OTE setup is **invalidated** when:

1. **Price closes beyond 100%** — If price retraces past the full swing, the OTE is invalid
2. **No LTF confirmation at OTE** — Price enters OTE but doesn't show a CHOCH/MSS
3. **Structure broken against you** — HTF structure shifts while you're waiting for entry
4. **Kill Zone expired** — If OTE forms outside of Kill Zone, lower probability

## Common OTE Mistakes

<Callout type="warning" title="Avoid These">

**❌ Drawing Fib on wrong swing** — Use the MOST RECENT and RELEVANT expansion leg, not random swings.

**❌ Entering at 38.2% or 50%** — These are too shallow. The institutional sweet spot is 61.8-78.6%. Be patient.

**❌ No confluence at OTE** — OTE alone is not enough. You need an OB, FVG, or structure level there too.

**❌ Entering without LTF confirmation** — Don't blindly limit order at OTE. Wait for CHOCH on 5M/15M.

**❌ Stop too tight within OTE** — Stop must be BEYOND the 100% level to give the trade room. Accept the wider stop and compensate with the excellent entry price.

</Callout>
