## What is ICT? (Institutional Client Terminal)

**ICT** is an advanced trading methodology that combines **time**, **market structure**, and **institutional behavior**.

Core idea: Institutional traders perform specific actions at specific times. Learn their entry times and profit.

---

## What is a Kill Zone?

A **Kill Zone** is a specific time period when the market is most alive and institutions execute massive moves.

### Types of Kill Zones:

```
1. European Kill Zone
   Time: 1:00 PM - 3:00 PM BD
   Trigger: London Open

2. New York Kill Zone
   Time: 8:30 PM - 10:30 PM BD
   Trigger: New York Open

3. Asian Kill Zone
   Time: 8:00 AM - 10:00 AM BD
   Trigger: Tokyo Open
```

## Kill Zone Mechanics

### What is a PD Array?

A **PD Array** (Previous Day Array) looks at yesterday's structure to predict today's institutional behavior.

```
Daily Range Setup:
High: 1.0950  ← Supply (sellers)
Low:  1.0850  ← Demand (buyers)

Range: 100 pips

Pre-Market (07:00-07:30)
  → Traders gathering

Kill Zone (08:00-09:30)
  → Institutions execute
  → Massive movement
  → Stop collection
  → Break of structure
```

### Kill Zone Timeline:

```
SESSION START    MID-POINT       SESSION END
    |              |               |
00:00 (Tokyo)                    Stop-hunts
06:00 (London Pre)
08:00 KILL-ZONE!  Biggest move   11:00
      (Start)                    (End)
```

## Kill Zone Strategy Rules

### The Core Principles:

```
Rule 1: Only enter IN kill zone
        Never before, never late

Rule 2: Watch for expansion
        Big candle = institutional activity

Rule 3: Break FVG or Order Block
        They're collecting retail stops

Rule 4: Score momentum
        Fast movement = zone is active
```

### Kill Zone Entry Checklist:

```
☐ Correct time period? (Kill Zone hours)
☐ Previous day range defined?
☐ PD Array identified?
☐ FVG or OB present?
☐ First hour expansion visible?
☐ CHOCH or BOS occurred?
☐ Momentum building?
```

## Common Kill Zone Mistakes

### Mistake 1: Wrong Entry Time

```
❌ Entering before 08:00
   Reason: Institutions still planning

✅ Enter after kill zone opens
   When you see expansion in first hour
```

### Mistake 2: Ignoring PRO

```
❌ Not measuring yesterday's range
   Reason: Can't understand PRO

✅ Always measure:
   • Yesterday's High
   • Yesterday's Low
   • Expected daily range
```

### Mistake 3: Ignoring News Events

```
❌ Trading during major news release
   Reason: Unexpected volatility spike

✅ Check event calendar
   Avoid red news times
```
