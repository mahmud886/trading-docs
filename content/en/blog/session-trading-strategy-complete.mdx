## What are Forex Sessions?

**The forex market runs 24 hours** but is divided into sessions:

```
Each session has:
• Different volume levels
• Different volatility profiles
• Different trading opportunities
```

---

## The Four Major Sessions

### Sydney Session (Quietest)

```
BD Time: 04:00 AM - 12:00 PM

Characteristics:
✓ Lowest volume
✓ Small movements (fewer pips)
✓ Limited trading opportunities
✗ Spreads can be wider

When to Trade:
→ Not for scalping
→ Only swing trades if needed
```

### Tokyo Session (Asian Power)

```
BD Time: 06:00 AM - 2:00 PM

Characteristics:
✓ Moderate volume
✓ JPY-based pairs are strong
✓ Good opportunities in Yen pairs
✓ Trend continuation likely

When to Trade:
→ EUROJPY, GBPJPY pairs
→ 6:00-7:00 AM ultra-quiet
→ 8:00-10:00 AM good activity
```

### London Session (The Giant!)

```
BD Time: 12:00 PM - 8:00 PM

Characteristics:
✓ HIGHEST volume!!!
✓ Maximum volatility
✓ Fast movements, big pips
✓ Best spreads
✓ Common economic data releases

When to Trade:
→ Traders' favorite session
→ EURUSD, GBPUSD, AUDJPY alive
→ 12:00-2:00 PM best period
```

### New York Session (Volatile)

```
BD Time: 8:00 PM - 4:00 AM

Characteristics:
✓ Second-highest volume
✓ US economic data (most impactful)
✓ Extreme volatility
✓ High risk/high reward

When to Trade:
→ Only for experienced traders
→ Be careful from 8:30 PM
→ Very dangerous on big news days
```

## Session Overlaps (The Best Times!)

### Overlap 1: Sydney-Tokyo (Asian Window)

```
BD Time: 6:00 AM - 12:00 PM

Profile:
✓ Asian currencies strong
✓ Moderate volume
✓ Decent opportunities

Best Pairs: AUDJPY, NZDJPY
```

### Overlap 2: London-Tokyo (Brief)

```
BD Time: 12:00 PM - 2:00 PM

Profile:
✓ Transition period
✓ Minimal overlap actually
✓ Volume starting to rise

Note: Too brief for most traders
```

### Overlap 3: London-New York (The Sweet Spot!)

```
BD Time: 8:00 PM - 12:00 AM (midnight)

Profile:
✓ ULTRA HIGH VOLUME!!!
✓ Most pips available
✓ STRONGEST trends
✓ Best opportunities overall
✓ Tightest spreads

Best Time: 8:00 PM - 9:30 PM (extreme action)

Best Pairs:
→ EURUSD (best)
→ GBPUSD
→ AUDUSD
→ USDCAD
```

### Overlap 4: New York-Sydney (Very Small)

```
BD Time: 3:00 AM - 4:00 AM

Profile:
✓ Very small window (1 hour)
✓ Low volume
✗ Avoid typically
```

## London Session Deep Dive

The most important session deserves detail!

### Complete London Timing (BD):

```
11:45 AM  Prep begins (minor pre-move)
12:00 PM  🔴 OPENING BELL! Explosion often
12:15 PM  First stop collection typical
12:30 PM  Retracement / consolidation
1:00 PM   Second push begins (strong)
1:30 PM   Final move continuation
2:00 PM   London strength peaks
2:30 PM   Often creates top or bottom
3:00 PM   Adjustment/potential reversal
```

### Why London Session is Best?

```
✓ Euro is world's 2nd currency (strong)
✓ UK data releases are predictable
✓ Euro-Dollar has best liquidity
✓ Institutions load during this session
✓ Trend almost always present
✓ Tight spreads, fast execution
✓ Consistent pattern repeats
```

## When NOT to Trade (Avoid These)

### Never Trade During:

```
❌ Major economic data releases
   (US Non-Farm Payroll, CPI, GDP, FOMC)
   → Unexpected spikes happen

❌ End of week / Friday night
   → Weekend gap risk

❌ Before major holidays
   → Low volume, choppy

❌ Bank holidays
   → Market closed or very thin
```
