## Why You Need a Checklist

Professional pilots, surgeons, and engineers all use checklists — because even experts make mistakes under pressure. Trading is no different. A pre-trade checklist:

- **Eliminates emotional entries** (FOMO, revenge, boredom)
- **Ensures confluence** (no single-factor trades)
- **Standardizes quality** (only A+ setups pass)
- **Improves consistency** (same process every time)
- **Reduces losses** (bad trades get filtered out)

<Callout type="tip" title="The Professional Standard">
  Every prop firm trader, institutional desk, and hedge fund has execution protocols. Your checklist IS your trading
  system in action. No checklist = no discipline = no consistency.
</Callout>

## The Complete Pre-Trade Checklist

### Phase 1: Market Context (Before Looking for Entries)

```
□ 1. HTF Bias Determined?
   - Daily/4H trend direction clear (bullish/bearish/range)
   - If range → Don't trade (or trade range edges only)
   - "What direction am I trading today?"

□ 2. Key Levels Marked?
   - Previous Day High/Low (PDH/PDL)
   - Previous Week High/Low (PWH/PWL)
   - 4H/Daily Order Blocks
   - Significant FVGs
   - Equal Highs/Lows (Liquidity Pools)
   - Round Numbers near price

□ 3. Economic Calendar Checked?
   - Any high-impact news in next 2 hours?
   - If yes: Wait until after release
   - If no: Proceed with normal strategy

□ 4. Session Timing Correct?
   - Currently in Kill Zone? (London 02:00-05:00 or NY 08:30-11:00 EST)
   - If outside Kill Zone → NO TRADE
   - "Am I in the right window?"
```

### Phase 2: Setup Identification (Finding the Trade)

```
□ 5. Liquidity Sweep Observed?
   - Has price taken a key level (SSL/BSL)?
   - Sweep = Wick beyond level + rejection
   - "Has Smart Money collected fuel?"

□ 6. Market Structure Shift?
   - CHOCH or BOS on LTF (15M/5M)?
   - Displacement with FVG?
   - "Has direction been confirmed?"

□ 7. POI Identified?
   - Valid Order Block OR Fair Value Gap?
   - POI in correct Premium/Discount zone?
   - First touch? (Not 3rd/4th test)
   - "Where exactly am I entering?"

□ 8. Confluence Count (Minimum 3)?
   - HTF Trend alignment ✓
   - Premium/Discount correct ✓
   - OB or FVG present ✓
   - Liquidity swept ✓
   - Session timing ✓
   - Count: ___ / 5 (Need ≥ 3)
```

### Phase 3: Execution Details (Taking the Trade)

```
□ 9. Entry Price Defined?
   - Exact price or zone for entry
   - Limit order or market order plan
   - "At what price am I entering?"

□ 10. Stop Loss Placed?
   - Beyond structural invalidation
   - Not too tight (room for wicks)
   - Not too wide (reasonable risk)
   - "Where is my idea WRONG?"

□ 11. Take Profit Planned?
   - TP1: Nearest liquidity/structure (1:2 minimum)
   - TP2: Extended target (1:3+)
   - Runner: Trail to major level
   - "Where is my idea COMPLETE?"

□ 12. R:R Calculated?
   - Minimum 1:2 Risk:Reward
   - Ideally 1:3 or better
   - If less than 1:2 → NO TRADE
   - "Is this trade WORTH the risk?"

□ 13. Position Size Calculated?
   - Risk = Maximum 1% of account
   - Size = (Account × Risk%) ÷ (Stop in $ or pips × pip value)
   - NEVER guess — always calculate
   - "Am I risking the right amount?"
```

### Phase 4: Final Emotional Check

```
□ 14. Am I Emotionally Neutral?
   - Not angry from recent loss (revenge)
   - Not excited from recent win (overconfidence)
   - Not bored (forcing trades)
   - Not anxious (FOMO)
   - "Would I take this trade on a funded account?"

□ 15. Daily Limits Not Hit?
   - Under maximum trade count for the day
   - Under daily loss limit (3%)
   - No consecutive loss situation requiring break
   - "Do I have permission to take this trade?"
```

## Quick One-Line Version (Print This)

```
Before EVERY entry, confirm:
1. HTF Bias? → Direction clear
2. Kill Zone? → Correct timing
3. Liquidity Swept? → Fuel collected
4. Structure Shift? → CHOCH/BOS confirmed
5. POI? → OB/FVG in P&D
6. Confluence ≥ 3? → Multiple factors
7. Stop Defined? → Invalidation clear
8. R:R ≥ 1:2? → Worth the risk
9. Size Calculated? → 1% max
10. Emotional? → Neutral state

ALL 10 = YES → EXECUTE
ANY = NO → SKIP
```

## Post-Trade Checklist (Equally Important)

### After Every Trade (Win or Loss):

```
□ Screenshot taken (Entry, exit, full context)
□ R:R recorded (Planned vs Actual)
□ Journal entry written:
  - What was the setup?
  - Did it follow the pre-trade checklist?
  - What did I do well?
  - What could I improve?
  - Emotional state during trade?
□ Discipline score (1-10)
□ Category: A+ setup / B setup / Emotional trade

Weekly: Review all trades against checklist
- How many followed ALL criteria?
- How many violated criteria?
- What's the win rate difference between the two?
```

## Checklist by Trade Type

### Scalp (5-15 min hold)

```
Essential:
□ Kill Zone timing (London/NY only)
□ 5M CHOCH/BOS confirmed
□ FVG entry within last 5 candles
□ Stop: Below LTF structure (10-15 pips)
□ Target: Next LTF liquidity (1:2 minimum)
□ Time limit: If not hit in 30 min → Close/trail
```

### Intraday (1-4 hour hold)

```
Essential:
□ 4H bias aligned
□ 15M entry confirmation (CHOCH + FVG/OB)
□ Sweep at session level (Asian/London H/L)
□ Stop: Beyond 15M structure
□ Target: Session high/low or PDH/PDL
□ Manage: Partials at 1:2, trail rest
```

### Swing (1-5 day hold)

```
Essential:
□ Daily/Weekly bias aligned
□ 4H entry confirmation
□ Major liquidity swept (Weekly/Monthly level)
□ Stop: Beyond 4H structure (wider acceptable)
□ Target: Next weekly level
□ Patience: Let trade develop over sessions
□ Trail with Daily structure (not intraday noise)
```

## Common Execution Mistakes

<Callout type="warning" title="These Break Your Edge">

**1. Skipping the checklist** — "I just know this is a good trade" → Usually isn't.

**2. Entering before confirmation** — Anticipating instead of confirming = gambling.

**3. Moving stop after entry** — Decided it was too tight → Loss becomes bigger.

**4. No take profit plan** — Holding hoping for more → Gives back profit.

**5. Over-sizing** — "This one is special" → It's not. Same 1% every time.

**6. Not journaling** — Can't improve what you don't track.

**7. Trading outside Kill Zones** — Boredom-driven entries during Asian session.

</Callout>

## Building Your Personal Checklist

```
Step 1: Start with this template
Step 2: After 30 trades, review:
  - Which criteria saved you from bad trades?
  - Which criteria you keep violating?
  - Add any personal rules (specific pair, specific session)
Step 3: Simplify to YOUR essential criteria
Step 4: Print it, put it next to monitor
Step 5: NEVER take a trade that doesn't pass

Your checklist should:
- Fit on ONE page (or screen)
- Take under 60 seconds to complete
- Be binary (Yes/No, not "maybe")
- Be non-negotiable (No exceptions)
```

## Key Takeaways

| Concept         | Rule                                             |
| --------------- | ------------------------------------------------ |
| **Purpose**     | Eliminate emotional, random trades               |
| **Items**       | 10-15 maximum (keep it simple)                   |
| **Standard**    | ALL items must pass — no exceptions              |
| **Result**      | Only A+ setups survive the filter                |
| **Speed**       | Under 60 seconds to complete                     |
| **Format**      | Binary Yes/No (no "maybe")                       |
| **Review**      | Journal + Weekly review against checklist        |
| **Improvement** | Track win rate: Checklist vs No-Checklist trades |

Good execution is as important as the trade idea. Plan entries and exits, follow the checklist every time, and your results will transform.
