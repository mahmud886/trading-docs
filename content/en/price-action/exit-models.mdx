## Exit Strategy Matters

Your exit determines **actual profit**. A perfect entry with bad exit = mediocre results.

---

## Exit Types

### 1. Fixed Target

- Next S/R level
- Measured move (pattern height)
- Fibonacci extension (127.2%, 161.8%)
- Risk multiple (always 2R or 3R)

### 2. Structural Exit

- Next opposing swing high/low
- Opposing Order Block
- Liquidity pool (equal H/L)
- Previous session H/L

### 3. Trailing Stop

- Behind each new swing point
- Behind 20 EMA
- ATR-based (1.5× ATR distance)
- Break-even after 1R

### 4. Partial Exit (Scaling Out)

- 50% at 1:1 R:R → move SL to BE
- 30% at 1:2 R:R
- 20% trailing to final target

### 5. Time-Based

- End of session (intraday)
- 24-48 hours post-entry (swing)
- Stale trades rarely become winners

---

## Style Recommendations

| Style    | Best Exit                |
| -------- | ------------------------ |
| Scalping | Fixed target (5-20 pips) |
| Intraday | Structural + time        |
| Swing    | Partial + trailing       |
| Position | Structural + trailing    |

---

## Exit Rules

1. Plan exit BEFORE entry
2. Never move TP further away
3. Partial profits reduce pressure
4. Respect opposing levels
5. Time stops work for stale trades
