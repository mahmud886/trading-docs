## How Wyckoff Relates to SMC

Wyckoff theory (1930s) describes the same institutional behavior that SMC codifies. Wyckoff called it "Composite Man" — SMC calls it "Smart Money." The concepts are the same; only the terminology differs.

---

## Wyckoff → SMC Translation

| Wyckoff Term | SMC Equivalent | Meaning |
|-------------|---------------|----------|
| Accumulation | Accumulation | Buying at discount |
| Distribution | Distribution | Selling at premium |
| Markup | Delivery (bullish) | Price rising |
| Markdown | Delivery (bearish) | Price falling |
| Spring | Liquidity Sweep (SSL) | False breakdown |
| UTAD (Upthrust) | Liquidity Sweep (BSL) | False breakout |
| Creek/Ice | Key structure level | BOS level |
| SOS (Sign of Strength) | BOS | Break of structure |
| SOW (Sign of Weakness) | CHOCH | Change of character |
| Composite Man | Smart Money | Institutional players |

---

## Wyckoff Accumulation = SMC Accumulation

```
Wyckoff Phases:        SMC Reading:
Phase A (Selling Climax) = Markdown exhaustion, initial demand
Phase B (Building Cause) = Range, Order Blocks forming
Phase C (Spring)          = Liquidity sweep below range
Phase D (SOS + BOS)       = Break of structure bullish
Phase E (Markup)          = Expansion/delivery
```

---

## Using Both Together

1. **Wyckoff gives context** — Which phase is the market in?
2. **SMC gives entry** — Where exactly to enter (OB, FVG)
3. **Together** = understanding the WHY (Wyckoff) + the WHERE (SMC)
