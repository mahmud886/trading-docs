## What is a Breaker Block?

A Breaker Block is a **failed Order Block that flips polarity**. When an Order Block gets broken (violated), it doesn't disappear — it transforms into a Breaker Block that now acts as support/resistance from the opposite direction.

<Callout type="info" title="Failed OB = New Opportunity">
  When a bullish OB fails (price breaks below it), the entire OB zone becomes a bearish Breaker Block. Price often
  returns to this zone before continuing lower — giving you an entry.
</Callout>

---

## How Breaker Blocks Form

```
Bullish Breaker Block:
1. Bearish Order Block exists (last green candle before drop)
2. Price drops, creating lower lows
3. Then price REVERSES and breaks ABOVE the bearish OB
4. The broken bearish OB = Bullish Breaker Block
5. Price returns to test this zone as SUPPORT
6. Entry: Long at the Breaker Block retest

Bearish Breaker Block:
1. Bullish Order Block exists (last red candle before rally)
2. Price rallies, creating higher highs
3. Then price REVERSES and breaks BELOW the bullish OB
4. The broken bullish OB = Bearish Breaker Block
5. Price returns to test this zone as RESISTANCE
6. Entry: Short at the Breaker Block retest
```

---

## Identification Rules

| Rule         | Requirement                                          |
| ------------ | ---------------------------------------------------- |
| Origin       | Must be a valid Order Block first                    |
| Break        | OB must be completely violated (candle close beyond) |
| Flip         | Old OB now acts as opposite S/R                      |
| Retest       | Price returns to test the broken zone                |
| Confirmation | Rejection candle at the Breaker                      |

---

## Breaker vs. Order Block

| Feature     | Order Block             | Breaker Block              |
| ----------- | ----------------------- | -------------------------- |
| Status      | Active, unbroken        | Broken, flipped            |
| Direction   | Same as original        | Opposite to original       |
| Trade       | With original direction | With new direction         |
| Reliability | Fresh = strongest       | After clear break = strong |

---

## Trading Breaker Blocks

```
1. Identify Order Block that has been clearly broken
2. Mark the broken OB zone = Breaker Block
3. Wait for price to return to the Breaker zone
4. Enter in the NEW direction (opposite to original OB)
5. Stop: Beyond the Breaker Block zone
6. Target: Next liquidity or structural level
```
