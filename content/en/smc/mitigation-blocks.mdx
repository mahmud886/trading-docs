## What is a Mitigation Block?

A Mitigation Block is an **Order Block that was partially filled** on its first revisit but not fully traded through. When price returns a second time, the REMAINING unfilled portion of the OB acts as a refined entry zone — the "mitigation" zone.

<Callout type="info" title="Second Chance Entry">
Think of a mitigation block as a "second chance" entry at an OB that was already tested once. The unfilled portion still holds institutional interest.
</Callout>

---

## How Mitigation Blocks Form

### The Process
1. **OB forms** — Last opposing candle before displacement
2. **First Return** — Price retraces to the OB, enters partially, then moves away
3. **The OB is NOT fully filled** — Price only wicked into 50-70% of the OB
4. **Second Return** — Price comes back again to the remaining unfilled portion
5. **This unfilled portion = Mitigation Block**

---

## Mitigation Block vs Order Block

| Feature | Order Block | Mitigation Block |
|---------|------------|------------------|
| **Touch Count** | First touch (fresh) | Second touch (mitigated) |
| **Strength** | Strongest | Slightly weaker |
| **Stop Width** | Full OB range | Only unfilled portion |
| **R:R Potential** | Standard | Tighter stop = better R:R |

## Real Example: EUR/USD Mitigation Block

- **15M Bullish OB** at 1.0845 - 1.0855
- **First return:** Price dips to 1.0851 then rallies (OB partially filled)
- **Second return:** Price dips to 1.0847 (the unfilled lower portion)
- **Mitigation Block:** 1.0845 - 1.0847 (remaining portion)
- **Entry:** Buy at 1.0847
- **SL:** 1.0842 (only 5 pips — much tighter than full OB)
- **TP:** 1.0900 (BSL target)
- **R:R:** 1:10.6

## Common Mistakes

<Callout type="warning" title="Mitigation Block Errors">

**❌ Treating all second touches as mitigation** — The OB must have been only PARTIALLY filled first time

**❌ Using weak OBs** — Only valid OBs (with displacement) create valid mitigation blocks

**❌ No HTF alignment** — Mitigation blocks still need HTF bias confirmation

</Callout>
