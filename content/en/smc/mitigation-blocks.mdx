## Two Meanings of "Mitigation"

The term is used in two different ways, and mixing them up causes confusion:

| Usage                           | Meaning                                                                                    | Trade                                        |
| ------------------------------- | ------------------------------------------------------------------------------------------ | -------------------------------------------- |
| **Mitigation block** (ICT)      | An order block that **failed** after the move from it **could not make a new high or low** | The **opposite** direction, on the retest    |
| **"Mitigated" OB** (common SMC) | An order block that price has **already returned to** and reacted from                     | The **same** direction, but weaker each time |

<Callout type="warning" title="Corrected: definition">
  The original page used only the second meaning and called it a "mitigation block". On this site, a **mitigation
  block** follows the ICT definition, matching the [Breaker Blocks](/en/smc/breaker-blocks) and [ICT PD
  Arrays](/en/ict/pd-arrays) lessons. A tested OB is covered at the end of this page and in [Fresh vs Tested
  Zones](/en/smc/fresh-vs-tested).
</Callout>

## Mitigation Block vs Breaker Block

| Feature           | Breaker block                            | Mitigation block                    |
| ----------------- | ---------------------------------------- | ----------------------------------- |
| Move from the OB… | **Made a new extreme** (swept liquidity) | **Failed** to make a new extreme    |
| Then              | Closes through the OB                    | Closes through the OB               |
| Trade             | Retest, opposite direction               | Retest, opposite direction          |
| What it shows     | A trap after a liquidity grab            | Weakness: the trend ran out of fuel |

Both are traded the same way. The breaker usually comes with more trapped traders (those who chased the sweep), so many traders rate it slightly higher.

---

## Trading It

1. Find an OB in a trend.
2. Check the next swing from it: **no new high** (for a bullish OB) or **no new low** (for a bearish OB).
3. Wait for a **close through** the OB.
4. Sell (or buy) the **retest** of the zone from the other side.
5. **Stop** beyond the OB candle; **target** the next liquidity.

## "Mitigated" Order Blocks (the Other Usage)

When price returns to an OB and reacts, some of the orders there are filled. Each return leaves fewer:

| Status                           | Trade quality               |
| -------------------------------- | --------------------------- |
| **Fresh** (untested)             | Best                        |
| **Tested once**, strong reaction | Still tradeable             |
| **Tested twice**                 | Only with strong confluence |
| **Tested 3+ times**              | Avoid: more likely to break |

These are rules of thumb. The original's "after 2–3 mitigations, the level is likely exhausted" is a common belief, not a measured statistic.

## Common Mistakes

| Mistake                                   | Fix                                                    |
| ----------------------------------------- | ------------------------------------------------------ |
| Mixing up the two meanings                | Mitigation block = failed OB; mitigated OB = tested OB |
| Not checking whether a new extreme formed | That decides breaker vs mitigation                     |
| Entering on the break                     | Wait for the retest                                    |
| Trading a 3rd test of an OB               | Usually skip                                           |

## Practice

1. Find 10 failed order blocks on 1H charts.
2. Label each as breaker (new extreme first) or mitigation block (no new extreme).
3. Record how each retest reacted. Log it in your [trading journal](/en/tools/journal-template).

## Summary

| Element              | Rule                                                    |
| -------------------- | ------------------------------------------------------- |
| **Mitigation block** | OB fails after a swing that couldn't make a new extreme |
| **Entry**            | Retest from the other side                              |
| **Stop**             | Beyond the OB candle                                    |
| **Tested OB**        | Same direction, weaker with each test                   |
