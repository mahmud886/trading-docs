## Pips, Points & Basic Trading Terminology

Understanding trading terminology is essential for reading charts, discussing trades, and managing positions.

### Pip (Percentage in Point)

**Definition:** The smallest price increment in currency quotes

**Value:** Usually 0.0001 (four decimal places for most currencies)

**Example EUR/USD:**
- Price move from 1.0950 to 1.0951 = 1 pip movement
- Price move from 1.0950 to 1.0960 = 10 pips movement

**Calculation:**
```
New Price - Old Price = Pips Movement
1.0960 - 1.0950 = 0.0010 = 10 pips
```

**Pip Value in Dollars:**
For 1 lot (100,000 units) of EUR/USD:
- 1 pip = $10
- 10 pips = $100
- 100 pips = $1,000

**For 0.1 lot (10,000 units):**
- 1 pip = $1
- 10 pips = $10
- 100 pips = $100

### Points vs Pips

**Points:** Same as pip (used interchangeably in forex)
- "The price moved 10 points" = 10 pips

**Stocks & Indices:**
- 1 point = 1% increments (not same as forex pip)
- S&P 500 up 50 points = 50 × $250 = $12,500 value change

### Tick

**Definition:** The smallest incremental move a price can make

**Forex:**
- Usually 1 tick = 1 pip (0.0001)
- Some brokers show fractional pips (5 decimal places)
- Then 1 tick = 0.1 pip

**Stocks:**
- 1 tick = $0.01 (one cent)
- Varies by price-level regulations

**Futures:**
- Varies by contract
- Oil: 0.01 per tick
- Gold: 0.10 per tick

### Lot Size

**Definition:** Standard unit of trading volume

**Standard Lot:**
- 100,000 units of base currency
- "1 lot" of EUR/USD = 100,000 euros

**Mini Lot:**
- 10,000 units
- "0.1 lot" or "1 mini lot"
- 1/10th the size of standard

**Micro Lot:**
- 1,000 units
- "0.01 lot" or "1 micro lot"
- 1/100th of standard

**Nano Lot:**
- 100 units (rarely used)
- For very small accounts

**Lot Size Comparison:**
```
1 Standard Lot = 100,000 units
10 Mini Lots = 100,000 units (same)
100 Micro Lots = 100,000 units (same)
```

### Pip Value vs Lot Size

**Pip values for EUR/USD:**

**1 Standard Lot (100,000):**
- 1 pip = $10
- 10 pips = $100
- 100 pips = $1,000

**1 Mini Lot (10,000):**
- 1 pip = $1
- 10 pips = $10
- 100 pips = $100

**1 Micro Lot (1,000):**
- 1 pip = $0.10
- 10 pips = $1
- 100 pips = $10

### Easy Pip Calculation

**Formula:**
Pips Moved × Lot Size × Pip Value = Profit/Loss

**Example:**
- Lot size: 0.5 standard
- Pips moved: +50 pips
- Pip value: $10 (0.5 × $10 = $5 per pip)
- **Profit: 50 × $5 = $250**

### Price Quotations Explained

**EUR/USD Quote: 1.0950/1.0952**
- **Bid:** 1.0950 (what you receive if selling)
- **Ask:** 1.0952 (what you pay if buying)
- **Quote spread:** 2 pips
- Read as: "1.0950 bid, offered at 1.0952"

**GBP/USD Quote: 1.2500/1.2505**
- 5 pip spread (wider than EUR typically)

**USD/JPY Quote: 150.50/150.53**
- Quote may show 2 decimal places
- Still represents same pip spread

### Bid-Ask in Pips

**Common Quote:** EUR/USD 1.0950/1.0952

Breaking it down:
```
Bid:  1.0950 (large figure: 1.09)
Ask:  1.0952 (large figure: 1.09)
Spread: 2 pips (0.0002)
```

**In trader shorthand:**
- "Offered at 50/52" (meaning 1.0950/1.0952)
- "Two pip spread" (difference between 50 and 52)

### Handle (Large Figure)

**Definition:** The first few decimal places that rarely change

**Example:**
EUR/USD quotes might be:
- 1.0940 / 1.0942
- 1.0941 / 1.0943
- 1.0942 / 1.0944

**Traders would say:** "40 bid, 42 offered" (omitting the 1.09 handle)

The "handle" (1.09) is understood and not repeated

### PIP CONVERSION REFERENCE

**Important for different pairs:**

**EUR/USD (Standard):**
- 1 pip = 0.0001
- 1 standard lot = $10 per pip
- 1 mini lot = $1 per pip

**USD/JPY (Different!)**
- 1 pip = 0.01 (not 0.0001!)
- 1 standard lot = $10 per pip (coincidentally same)
- 100 pips = $1,000

**GBP/USD (Standard):**
- 1 pip = 0.0001
- 1 standard lot = $10 per pip
- Same as EUR

**USD/CAD (Standard):**
- 1 pip = 0.0001
- 1 standard lot = $10 per pip
- Same as EUR

### Base vs Quote Currency

**Pair: EUR/USD**
- **Base currency:** EUR (euro)
- **Quote currency:** USD (dollar)
- Price shows how many dollars needed to buy 1 euro

**How pips work:**
- Pips are in the quote currency (USD)
- USD/JPY exception: pips in base currency

### Real-World Calculations

**Trade Example 1:**
- Pair: EUR/USD
- Buy 0.5 lots at 1.0950
- Sell at 1.0970 (20 pip profit)
- Pip value (0.5 lot): $5 per pip
- **Profit: 20 × $5 = $100**

**Trade Example 2:**
- Pair: GBP/USD
- Buy 0.1 lots at 1.2500
- Sell at 1.2550 (50 pip profit)
- Pip value (0.1 lot): $1 per pip
- **Profit: 50 × $1 = $50**

**Trade Example 3:**
- Pair: USD/JPY
- Buy 1 mini lot at 150.50
- Sell at 150.80 (30 pips)
- Pip value (0.1 lot): $1 per pip
- **Profit: 30 × $1 = $30**

### Summary of Key Terms

| Term | Meaning |
|------|---------|
| **Pip** | 0.0001 (smallest price move in most pairs) |
| **Point** | Same as pip (used interchangeably) |
| **Tick** | Smallest increment (1 pip for most forex) |
| **Lot** | 100,000 units (standard), 10,000 (mini), 1,000 (micro) |
| **Handle** | First few decimal places of quote |
| **Spread** | Difference between bid and ask |
| **Base** | First currency in pair |
| **Quote** | Second currency in pair |
| **Pip Value** | Dollar value of 1 pip movement |
