## Institutional Order Flow কী?

SMC তে **Institutional Order Flow** মানে **বড় অংশগ্রহণকারীরা বর্তমানে কোন দিকে ঠেলছে**, Price থেকেই পড়া। তাদের অর্ডার দেখা যায় না, কিন্তু প্রভাব দেখা যায়:

- তাদের **জোন টিকে থাকে**: পুলব্যাক তাদের Order Block আর FVG তে থেমে যায়।
- তাদের **ভাঙন এগিয়ে যায়**: প্রতিটি পুলব্যাকের পরে একই দিকে নতুন BOS আসে।

এটা বন্ধ হলে Order Flow বদলাচ্ছে।

<Callout type="info" title="সংশোধিত: এক্সিকিউশনের দাবি">
  মূল লেসনে প্রাতিষ্ঠানিক সাইজ "১০০–১০,০০০+ লট" আর বলা হয়েছিল তারা "Liquidity সাজায়, তারপর পূর্ণ করে"। অর্ডারের সাইজ
  অনেক ভিন্ন হয়, আর সাজানো একটা উদ্দেশ্য যা কেউ দেখতে পায় না। যা কাজের আর দেখা যায় তা নিচে: টিকে থাকা জোন, এগিয়ে
  যাওয়া ভাঙন, আর তারা যে Liquidity লক্ষ্য করে।
</Callout>

## কেন বড় অর্ডার ছাপ রেখে যায়

| সীমাবদ্ধতা                   | চার্টে ছাপ                                              |
| ---------------------------- | ------------------------------------------------------- |
| একসাথে সব পূর্ণ করতে পারে না | Position তৈরির সময় রেঞ্জ আর পুলব্যাক                   |
| অন্য পক্ষ দরকার              | ঘোরার আগে Liquidity তে (পুরনো High/Low) Move            |
| দৃঢ়ভাবে প্রতিশ্রুতি দেয়    | **Displacement**: বড় ক্যান্ডেল, FVG                    |
| নিজের লেভেল রক্ষা করে        | রিটেস্টে টিকে থাকা **Order Block**                      |
| লিকুইড সময়ে কাজ করে         | বড় Move গুলো [Kill Zone](/bn/smc/kill-zones) এ জমা হয় |

| ধাপ  | কী হয়                                        | Order Flow            |
| ---- | --------------------------------------------- | --------------------- |
| OB ১ | পুলব্যাক OB তে টিকে থাকে, তারপর BOS           | **Bullish**           |
| OB ২ | পুলব্যাক আবার টিকে থাকে, আরেকটি BOS           | **Bullish**           |
| OB ৩ | একটি ক্যান্ডেল OB এর **মধ্য দিয়ে** ক্লোজ করে | **Bearish এ উল্টায়** |

Bullish থাকাকালীন শুধু Bullish জোনে Buy খোঁজেন। উল্টানোর পরে Bullish জোন ভাঙার আর [Breaker](/bn/smc/breaker-blocks) হওয়ার সম্ভাবনা বেশি; তখন Sell খোঁজেন।

## অনুশীলন

1. একটি 4H চার্টে এক মাস ধরে প্রতিটি পুলব্যাকের Order Block মার্ক করুন।
2. প্রতিটির জন্য লিখুন: টিকেছে (আর BOS এসেছে) নাকি ব্যর্থ।
3. Order Flow কোথায় উল্টেছে আর এরপর কী এসেছে মার্ক করুন। আপনার [ট্রেডিং জার্নালে](/bn/tools/journal-template) লিখুন।
