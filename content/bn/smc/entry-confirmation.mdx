## Entry Confirmation কী?

Entry Confirmation হলো আপনার Point of Interest (POI) এ এন্ট্রির আগে **শেষ ট্রিগার**: Higher Timeframe এ মার্ক করা Order Block, FVG বা অন্য Zone।

Price POI ছুঁলেই Zone টা হোল্ড করবে এমন নয়। Confirmation হলো Lower Timeframe এ প্রমাণ যে Price সত্যিই সেখানে রিঅ্যাক্ট করছে। বিনিময়: **যত বেশি প্রমাণের অপেক্ষা করবেন, এন্ট্রি প্রাইস তত খারাপ, R:R তত কম।**

## Confirmation এর পদ্ধতি

### ১. Lower Timeframe CHOCH (সবচেয়ে শক্তিশালী)

1. Price আপনার HTF POI তে পৌঁছায়।
2. 5m বা 15m চার্টে নামুন।
3. ট্রেডের দিকে CHOCH এর অপেক্ষা করুন: শেষ Lower High (Long এর জন্য) বা Higher Low (Short এর জন্য) এর ওপারে Close।
4. CHOCH এর রেখে যাওয়া FVG বা OB তে রিট্রেসে এন্ট্রি নিন।
5. Stop CHOCH তৈরি করা Swing এর ওপারে, অথবা POI এর ওপারে।

### ২. Displacement + নতুন FVG

POI থেকে দূরে একটি শক্তিশালী, বড় Body র ক্যান্ডেল যা FVG রেখে যায়। এটা সাধারণত নিজেই CHOCH ক্যান্ডেল, তাই এটা আর পদ্ধতি ১ প্রায়ই একসাথে আসে। নতুন FVG তে রিট্রেসে এন্ট্রি নিন।

### ৩. ক্যান্ডেল প্যাটার্ন

POI তে Engulfing ক্যান্ডেল, Pin Bar বা শক্তিশালী Close। এটা সবচেয়ে আগের আর সবচেয়ে দুর্বল Confirmation, তাই অন্য Confluence এর সাথে ব্যবহার করুন।

<Callout type="info" title="স্পষ্ট করা: ক্রম">
  মূল লেসনে "Displacement + FVG" কে CHOCH এন্ট্রির চেয়ে বেশি R:R বলা হয়েছিল। দুটো সাধারণত একই Move: Displacement
  ক্যান্ডেলই Structure ভাঙে। R:R বদলায় আপনি কোথায় এন্ট্রি নেন আর Stop কোথায় রাখেন তাতে, ট্রিগারের নামে নয়।
</Callout>

| ---- | ----------------------------- | ------------ | -------------- |

| ২    | Displacement ক্যান্ডেল Close  | বেশি         | দেরিতে         |

## সেটআপ গ্রেডিং

নেওয়ার আগে প্রতিটি সেটআপের স্কোর করুন:

| মানদণ্ড                                    | ✓   |
| ------------------------------------------ | --- |
| Higher Timeframe ট্রেন্ড একমত              |     |
| POI Unmitigated (প্রথম ছোঁয়া)             |     |
| POI Discount এ (Long) বা Premium এ (Short) |     |
| LTF Confirmation (CHOCH) আছে               |     |
| [Kill Zone](/bn/smc/kill-zones) এর ভিতরে   |     |

| স্কোর | গ্রেড | করণীয়          |
| ----- | ----- | --------------- |
| ৫ / ৫ | A+    | স্বাভাবিক রিস্ক |
| ৩–৪   | B     | কম রিস্ক        |
| ০–২   | C     | বাদ দিন         |

এটা ধারাবাহিকতার জন্য একটা চেকলিস্ট, মাপা Win Rate নয়। জার্নালে গ্রেড অনুযায়ী নিজের ফলাফল ট্র্যাক করুন, দেখুন A+ সেটআপ আপনার জন্য সত্যিই ভালো করে কি না।

### দ্বিতীয় উদাহরণ (চার্ট ছাড়া) — Gold, 4H OB তে Short

একটি 4H Bearish OB **2,418 – 2,425**। NY Kill Zone এ Price এটা ছোঁয়। 5m এ **2,412** এর নিচে CHOCH একটি FVG রেখে যায়; **2,414** এ রিট্রেসে Sell, Stop **2,427** OB এর উপরে, টার্গেট **2,385**: রিস্ক $13, রিওয়ার্ড $29, **R:R ১ : ২.২** (পরিকল্পিত)। একই Stop আর টার্গেটে OB এর নিচের দিকে (2,418) Risk Entry হলে R:R হতো ১ : ৩.৭, কিন্তু কোনো প্রমাণ ছাড়া।

## অনুশীলন

1. ২০টি HTF POI ছোঁয়া খুঁজুন।
2. প্রতিটির জন্য একই Stop আর টার্গেটে A, B আর C এন্ট্রি কোথায় হতো লিখুন।
3. কোনগুলো CHOCH তৈরির আগেই ব্যর্থ হয়েছে লিখুন: সেগুলো এমন লস যা শুধু Risk Entry নিয়েছে।
4. আপনার [ট্রেডিং জার্নালে](/bn/tools/journal-template) লিখুন।
