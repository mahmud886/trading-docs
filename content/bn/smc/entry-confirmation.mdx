## Entry Confirmation কী?

Entry Confirmation হলো Point of Interest (POI)-এ পৌঁছানোর পর Trade-এ Enter Validate করার **চূড়ান্ত Trigger**। SMC-তে শুধু Price OB Touch করলেই Enter করেন না — Smart Money React করছে এমন Confirmation অপেক্ষা করেন।

---

## Confirmation পদ্ধতি

### ১. LTF CHOCH (সেরা)
```
1. Price HTF POI-তে পৌঁছায় (OB, FVG ইত্যাদি)
2. Lower Timeframe-এ নামুন (M5/M15)
3. Trade Direction-এ CHOCH-এর জন্য অপেক্ষা
4. CHOCH-এর পর Enter
5. Stop: CHOCH Swing Point-এর বাইরে

সর্বোচ্চ CONFIDENCE Confirmation।
```

### ২. Displacement + FVG তৈরি
```
1. Price POI-তে পৌঁছায়
2. শক্তিশালী Displacement Candle দেখা দেয় (Marubozu-সদৃশ)
3. আপনার Direction-এ নতুন FVG তৈরি
4. নতুন FVG-তে Retracement-এ Enter
5. Institutional Commitment দেখায়
```

### ৩. Candle Confirmation
- POI-তে Engulfing Pattern
- POI-তে Pin Bar/Rejection
- আপনার Direction-এ শক্তিশালী Close
- দুর্বলতম Confirmation (Confluence-সহ ব্যবহার)
