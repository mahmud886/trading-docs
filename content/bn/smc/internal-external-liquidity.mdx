## ইন্টার্নাল বনাম এক্সটার্নাল লিকুইডিটি কী?

- **এক্সটার্নাল লিকুইডিটি** — মেজর সুইং হাই/লো, PDH/PDL, ইকুয়াল H/L (বড় টার্গেট)
- **ইন্টার্নাল লিকুইডিটি** — FVG, Order Block, একটি মুভের মধ্যে মাইক্রো সুইং পয়েন্ট (রিট্রেসমেন্ট টার্গেট)

<Callout type="info" title="সাইকেল">
প্রাইস এক্সটার্নাল লিকুইডিটি সুইপ ও ইন্টার্নাল লিকুইডিটি পূরণের মধ্যে ঘুরতে থাকে। এক্সটার্নাল সুইপ → ইন্টার্নাল ফিল (রিট্রেসমেন্ট) → পরবর্তী এক্সটার্নাল সুইপ।
</Callout>

## ইন্টার্নাল/এক্সটার্নাল সাইকেল

```
এক্সটার্নাল SSL সুইপ → ইন্টার্নাল FVG/OB তে রিট্রেস → এক্সটার্নাল BSL এ কন্টিনিউ
                           (আপনার এন্ট্রি)
```

### বাস্তব উদাহরণ: EUR/USD
1. **এক্সটার্নাল:** লন্ডনে SSL 1.0830 সুইপ
2. **ইন্টার্নাল:** 15M বুলিশ FVG 1.0855 তে রিট্রেস (আপনার এন্ট্রি)
3. **এক্সটার্নাল:** BSL 1.0920 এ কন্টিনিউ
4. **এন্ট্রি:** 1.0855 (ইন্টার্নাল), টার্গেট 1.0920 (এক্সটার্নাল), R:R 1:4+
