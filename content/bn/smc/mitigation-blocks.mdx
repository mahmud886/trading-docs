## Mitigation Block কী?

Mitigation Block হলো একটি **Order Block যা ইতিমধ্যে Price দ্বারা Test/Touch হয়েছে** কিন্তু সম্পূর্ণ ভাঙেনি। Price OB-তে ফিরে React করলে (আংশিক Fill), OB "Mitigated" হয় — এর অবশিষ্ট শক্তি কমে যায়।

<Callout type="warning" title="Mitigated = দুর্বল">
  Fresh, Unmitigated Order Block সবচেয়ে শক্তিশালী। Price প্রতিবার ফিরে React করলে OB গুরুত্ব হারায়। ২-৩ Mitigation-এর
  পর Level সম্ভবত Exhausted।
</Callout>

---

## Fresh vs. Mitigated

| Status                  | বর্ণনা            | Trade Quality        |
| ----------------------- | ----------------- | -------------------- |
| **Fresh (Unmitigated)** | কখনো Retest হয়নি | সর্বোচ্চ মান         |
| **1x Mitigated**        | একবার Test, ধরেছে | এখনো Tradeable       |
| **2x Mitigated**        | দুবার Test        | দুর্বল — সতর্কতা     |
| **3x+ Mitigated**       | ৩+ বার Test       | এড়িয়ে চলুন — ভাঙবে |

---

## Mitigation কীভাবে কাজ করে

```
1. 1.1000-এ Bullish OB তৈরি (Fresh)
2. Price Rally, তারপর OB-তে Pull Back
3. Price OB Touch করে, Bounce = 1st Mitigation
4. কিছু Institutional Order Fill, কিন্তু সব নয়
5. Price আবার Rally, আবার OB-তে Pull Back
6. 2nd Touch = 2nd Mitigation (এখন দুর্বল)
7. অবশেষে: OB Break (সব Order Fill/Exhausted)

নিয়ম: প্রথম Touch Trade করুন। 3rd+ Touch এড়িয়ে চলুন।
```

## Mitigation vs. Breaker

| বৈশিষ্ট্য | Mitigation Block             | Breaker Block   |
| --------- | ---------------------------- | --------------- |
| OB Status | Test হয়েছে কিন্তু ধরেছে     | সম্পূর্ণ ভেঙেছে |
| Direction | মূলের মতো                    | Flip (বিপরীত)   |
| Trade     | একই Direction (দুর্বল হচ্ছে) | নতুন Direction  |

---

## Trading নিয়ম

1. **সবসময় Fresh OB পছন্দ করুন** Mitigated-এর চেয়ে
2. **1st Mitigation** = Reaction শক্তিশালী হলে Valid
3. **2nd Mitigation** = শুধু শক্তিশালী Confluence-সহ
4. **3+ Mitigation** = সম্পূর্ণ এড়িয়ে চলুন
5. **Mitigation-এ সামান্য React** করলে = OB মরছে
