## Breaker Block কী?

Breaker Block হলো একটি **ব্যর্থ Order Block যা Polarity Flip করে**। Order Block ভেঙে গেলে (Violate) এটি অদৃশ্য হয় না — Breaker Block-এ রূপান্তরিত হয় যা এখন বিপরীত Direction থেকে Support/Resistance হিসেবে কাজ করে।

<Callout type="info" title="ব্যর্থ OB = নতুন সুযোগ">
Bullish OB ব্যর্থ হলে (Price নিচে Break), পুরো OB Zone Bearish Breaker Block হয়। Price প্রায়ই নিচে Continue করার আগে এই Zone-এ ফিরে আসে — আপনাকে Entry দেয়।
</Callout>

---

## Breaker Block কীভাবে তৈরি হয়

```
Bullish Breaker Block:
1. Bearish Order Block আছে (Drop-এর আগে শেষ Green Candle)
2. Price Drop করে, Lower Low তৈরি
3. তারপর Price REVERSE করে Bearish OB-এর উপরে BREAK
4. ভাঙা Bearish OB = Bullish Breaker Block
5. Price এই Zone SUPPORT হিসেবে Test করতে ফেরে
6. Entry: Breaker Block Retest-এ Long

Bearish Breaker Block:
1. Bullish Order Block আছে (Rally-র আগে শেষ Red Candle)
2. Price Rally করে, Higher High তৈরি
3. তারপর Price REVERSE করে Bullish OB-এর নিচে BREAK
4. ভাঙা Bullish OB = Bearish Breaker Block
5. Price এই Zone RESISTANCE হিসেবে Test করতে ফেরে
6. Entry: Breaker Block Retest-এ Short
```

---

## Breaker vs. Order Block

| বৈশিষ্ট্য | Order Block | Breaker Block |
|-----------|------------|---------------|
| Status | Active, অভঙ্গ | ভাঙা, Flip হয়েছে |
| Direction | মূলের মতো | মূলের বিপরীত |
| Trade | মূল Direction-এ | নতুন Direction-এ |
| নির্ভরযোগ্যতা | Fresh = সবচেয়ে শক্তিশালী | স্পষ্ট Break-এর পর = শক্তিশালী |

---

## Breaker Block Trade করা

```
1. স্পষ্টভাবে ভাঙা Order Block চিহ্নিত
2. ভাঙা OB Zone Mark = Breaker Block
3. Price Breaker Zone-এ ফেরার অপেক্ষা
4. নতুন Direction-এ Enter (মূল OB-এর বিপরীত)
5. Stop: Breaker Block Zone-এর বাইরে
6. Target: পরবর্তী Liquidity বা Structural Level
```
