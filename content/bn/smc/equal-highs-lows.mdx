## Equal High আর Low কী?

**Equal High (EQH)** আর **Equal Low (EQL)** হলো **প্রায় একই প্রাইসে** দুই বা ততোধিক Swing Point। এগুলো শক্ত Resistance বা Support মনে হয় বলে অনেক ট্রেডার এর ঠিক বাইরে Stop রাখে, Breakout অর্ডারও সেখানে। এতে এগুলো **ঘন Liquidity** হয়ে যায়।

| লেভেল          | Liquidity           | কার Stop…                       |
| -------------- | ------------------- | ------------------------------- |
| **Equal High** | Buy-Side, ঠিক উপরে  | Short দের; সাথে Breakout Buyer  |
| **Equal Low**  | Sell-Side, ঠিক নিচে | Long দের; সাথে Breakdown Seller |

**কতটা সমান হলে সমান?** নির্দিষ্ট নিয়ম নেই। ব্যবহারিক একটা: সেই Timeframe এর প্রায় **০.১ × ATR** এর মধ্যে, বা 1H ফরেক্স চার্টে কয়েক পিপ। হুবহু মিল কম হয়।

  ক্যান্ডেলগুলো ধারণাটা দেখানোর জন্য তৈরি **সিন্থেটিক**। এগুলো আসল প্রাইস বা আসল ট্রেড নয়। R:R হলো পরিকল্পিত

</Callout>

1. **1.0950** আর **1.0949** এ High, **1.0910** আর **1.0911** এ Low: দুই দিকে স্পষ্ট Stop সহ একটি রেঞ্জ।
2. **Sweep:** ১৫তম ঘণ্টা Equal High এর উপরে **1.0957** পর্যন্ত যায় আর 1.0946 এ নিচে ক্লোজ করে।
3. **এন্ট্রি:** Price নিচে ফিরলে **1.0942** এ Sell; Stop Sweep এর উপরে **1.0960**; টার্গেট উল্টো Pool এর ঠিক বাইরে **1.0905**।
4. **Run:** পতন Equal Low এর **মধ্য দিয়ে** ক্লোজ করে। সেই Pool রিভার্সাল ছিল না; ছিল টার্গেট।

| লেভেল   | প্রাইস      | নোট                            |
| ------- | ----------- | ------------------------------ |
| এন্ট্রি | 1.0942      | Equal High এর নিচে ফেরত        |
| Stop    | 1.0960      | 1.0957 Sweep এর উপরে           |
| টার্গেট | 1.0905      | Equal Low এর বাইরে             |
| **R:R** | **১ : ২.১** | রিস্ক ১৮ পিপ, রিওয়ার্ড ৩৭ পিপ |

<Callout type="warning" title="সংশোধিত: 'Sweep হবে আশা করুন'">
  মূল লেসনে বলা ছিল Equal লেভেল Sweep হবে আশা করুন, আর Sweep এর পরের জায়গাকে "উচ্চ সম্ভাবনার রিভার্সাল জোন" বলা
  হয়েছিল। Equal লেভেল **টার্গেট**, কিন্তু Price এগুলো **Run** করে চলেও যেতে পারে, যেমন এখানে Equal Low। শুধু ভিতরে ফিরে
  Close আর Structure এর Shift হলেই এটা রিভার্সাল সেটআপ।
</Callout>

## Equal লেভেল ট্রেড করা

| ধাপ | করণীয়                                                                |
| --- | --------------------------------------------------------------------- |
| ১   | আপনার Timeframe এ Equal High/Low (২+ স্পর্শ) মার্ক করুন               |
| ২   | EQH এর ভাঙনে বা EQL এর ভাঙনে অন্ধভাবে Buy/Sell করবেন না               |
| ৩   | অপেক্ষা: Sweep (ভিতরে ফিরে Close) নাকি Run (বাইরে Close আর ধরে রাখা)? |
| ৪   | Sweep এর পরে: Lower Timeframe CHOCH খুঁজুন, তারপর উল্টো দিকে এন্ট্রি  |
| ৫   | Sweep এর Wick এর বাইরে Stop                                           |
| ৬   | উল্টো Pool টার্গেট: EQH Sweep → EQL, আর উল্টোটা                       |

Displacement সহ **Run** এর পরে পুরনো লেভেল প্রায়ই Support (EQH এর জন্য) বা Resistance (EQL এর জন্য) হয়ে যায়।

## বেশি স্পর্শ: শক্তিশালী নাকি দুর্বল?

মূল লেসনে বলা ছিল "বেশি স্পর্শ = বেশি Liquidity = ভালো Sweep"। বেশি স্পর্শ মানে বেশি Stop, ঠিক। কিন্তু প্রতিটি স্পর্শ অন্য পাশের অর্ডারও শোষণ করে, তাই বহুবার টেস্ট হওয়া লেভেল **ভেঙে Run হওয়ার সম্ভাবনাও বেশি**। তিন বা তার বেশি স্পর্শকে লেভেলের মধ্য দিয়ে বড় Move আসছে এমন লক্ষণ হিসেবে দেখুন, আর কোন দিকে তা Close কে বলতে দিন।

## নিজের Stop কোথায় রাখবেন না

| আপনার ট্রেড       | এড়ান                    | ভালো                                             |
| ----------------- | ------------------------ | ------------------------------------------------ |
| EQH এর কাছে Short | EQH এর ১–২ পিপ উপরে Stop | সম্ভাব্য Sweep এর বাইরে, বা ট্রেড বাদ            |
| EQL এর কাছে Long  | EQL এর ১–২ পিপ নিচে Stop | সম্ভাব্য Sweep এর বাইরে, বা Sweep এর পরে এন্ট্রি |

## সাধারণ ভুল

| ভুল                              | সমাধান                                         |
| -------------------------------- | ---------------------------------------------- |
| প্রতিটি EQH/EQL কে রিভার্সাল ধরা | Close এর অপেক্ষা: Sweep নাকি Run               |
| ঠিক Equal লেভেলে Stop            | Pool টা সেখানেই                                |
| ১০ পিপ দূরের High কে "সমান" বলা  | আপনার Timeframe এর জন্য টলারেন্স ছোট রাখুন     |
| Higher Timeframe ট্রেন্ড উপেক্ষা | ট্রেন্ডে, ট্রেন্ডের দিকের Pool সাধারণত Run হয় |

## অনুশীলন

1. 1H চার্টে ১০ সেট Equal High/Low মার্ক করুন।
2. প্রতিটির জন্য লিখুন: Sweep (ভিতরে Close) নাকি Run (বাইরে Close)?
3. প্রতিবার Higher Timeframe ট্রেন্ড লিখুন। আপনার [ট্রেডিং জার্নালে](/bn/tools/journal-template) লিখুন।
