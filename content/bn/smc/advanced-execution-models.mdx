## SMC Execution Model

Execution Model নির্ধারণ করে POI চিহ্নিত করার পর কীভাবে Trade-এ Enter করবেন। আপনার নির্বাচিত Model R:R, Win Rate ও Move ক্যাপচার প্রভাবিত করে।

---

## তিনটি Model

### ১. Risk Entry (POI-তে Limit Order)

```
- সরাসরি OB/FVG-তে Limit Order
- Confirmation প্রয়োজন নেই
- সেরা R:R (1:4 থেকে 1:8)
- Win Rate: ~৪০-৫০%
- ব্যবহার: A+ Setup, সর্বোচ্চ Confluence
- ঝুঁকি: Reversal-এর আগে Sweep হতে পারে
```

### ২. Confirmation Entry (LTF CHOCH)

```
- POI-তে LTF Structural Shift অপেক্ষা
- CHOCH Confirmation-এর পর Enter
- মধ্যম R:R (1:2 থেকে 1:4)
- Win Rate: ~৫৫-৬৫%
- ব্যবহার: Standard Setup, মধ্যম Confidence
- ঝুঁকি: দ্রুত Move মিস, চওড়া Stop
```

### ৩. Refined Entry (CHOCH-এর মধ্যে FVG)

```
- LTF CHOCH অপেক্ষা, তারপর CHOCH-এর তৈরি
  FVG/OB-তে Enter
- উভয়ের সেরা
- R:R: 1:3 থেকে 1:6
- Win Rate: ~৫০-৬০%
- ব্যবহার: Precision + Confirmation চান
- ধৈর্য ও দক্ষতা প্রয়োজন
```

## কখন কোনটি ব্যবহার

| পরিস্থিতি                 | Model                | কারণ                       |
| ------------------------- | -------------------- | -------------------------- |
| Perfect A+ Confluence     | Risk Entry           | সর্বোচ্চ R:R, Zone বিশ্বাস |
| ভালো Setup, নিরাপত্তা চান | Confirmation         | বেশি Win Rate              |
| Precision চান             | Refined              | সেরা ভারসাম্য              |
| Counter-trend             | Confirmation/Refined | অতিরিক্ত প্রমাণ প্রয়োজন   |
| Scalping                  | Risk/Confirmation    | Speed গুরুত্বপূর্ণ         |
