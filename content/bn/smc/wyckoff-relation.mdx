## Wyckoff কীভাবে SMC-এর সাথে সম্পর্কিত

Wyckoff Theory (১৯৩০) একই Institutional Behavior বর্ণনা করে যা SMC Codify করে। Wyckoff একে "Composite Man" বলেছেন — SMC বলে "Smart Money।" Concept একই; শুধু Terminology আলাদা।

---

## Wyckoff → SMC অনুবাদ

| Wyckoff Term           | SMC সমতুল্য           | অর্থ                 |
| ---------------------- | --------------------- | -------------------- |
| Accumulation           | Accumulation          | Discount-এ কেনা      |
| Distribution           | Distribution          | Premium-এ বিক্রি     |
| Markup                 | Delivery (Bullish)    | Price বাড়া          |
| Markdown               | Delivery (Bearish)    | Price কমা            |
| Spring                 | Liquidity Sweep (SSL) | False Breakdown      |
| UTAD (Upthrust)        | Liquidity Sweep (BSL) | False Breakout       |
| Creek/Ice              | Key Structure Level   | BOS Level            |
| SOS (Sign of Strength) | BOS                   | Break of Structure   |
| SOW (Sign of Weakness) | CHOCH                 | Change of Character  |
| Composite Man          | Smart Money           | Institutional Player |

---

## Wyckoff Accumulation = SMC Accumulation

```
Wyckoff Phase:             SMC Reading:
Phase A (Selling Climax)  = Markdown Exhaustion, Initial Demand
Phase B (Building Cause)  = Range, Order Block তৈরি
Phase C (Spring)          = Range-এর নিচে Liquidity Sweep
Phase D (SOS + BOS)       = Bullish Break of Structure
Phase E (Markup)          = Expansion/Delivery
```
