## SMC Risk Management

SMC-তে Risk Management যথেচ্ছ Pip Distance-এর বদলে **Structural Invalidation** ব্যবহার করে। Stop যায় সেখানে যেখানে আপনার Thesis ভুল — Setup Invalidate করার Structural Level-এর বাইরে।

---

## SMC-তে Stop Placement

| Setup Type    | Stop অবস্থান                 | কারণ                       |
| ------------- | ---------------------------- | -------------------------- |
| OB Entry      | OB-এর বাইরে (Body, Wick নয়) | OB Violate = Thesis ভুল    |
| FVG Entry     | FVG Range-এর বাইরে           | FVG ভাঙা = Imbalance Fill  |
| Sweep Entry   | Sweep Wick-এর বাইরে          | নতুন Low/High = Sweep নয়  |
| CHOCH Entry   | CHOCH Swing Point-এর বাইরে   | Structure আসলে Shift হয়নি |
| Breaker Entry | Breaker Zone-এর বাইরে        | Breaker ব্যর্থ             |

## Position Sizing সূত্র

```
Lot Size = (Account × Risk%) ÷ (Stop Pip × Pip Value)

উদাহরণ:
- Account: $10,000
- Risk: 1% = $100
- Stop: 25 Pip (OB Width + Buffer)
- Pip Value: $10/Lot
- Size: $100 ÷ (25 × $10) = 0.40 Lot
```

## নিয়ম

1. **প্রতি Trade-এ সর্বোচ্চ ১-২%** — আলোচনাযোগ্য নয়
2. **দৈনিক সর্বোচ্চ ৩% Loss** — দিনের জন্য থামুন
3. **সাপ্তাহিক সর্বোচ্চ ৫% Loss** — পরবর্তী সপ্তাহে Size কমান
4. **Correlated Pair** একটি Risk Unit হিসেবে গণনা
5. **চওড়া Stop = ছোট Size** (Stop সরাবেন না)
6. **১R Gain-এর পর Break-even**
