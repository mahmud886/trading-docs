## Session Liquidity কী?

Session Liquidity বলতে বোঝায় **পূর্ববর্তী Session-এর High ও Low** পরবর্তী Session-এর Liquidity Target হিসেবে কাজ করা। SMC-তে প্রতিটি নতুন Session পূর্ববর্তী-র রেখে যাওয়া Liquidity নিতে চায়।

---

## মূল Session Liquidity Level

| Level              | সংক্ষেপ | তাৎপর্য           |
| ------------------ | ------- | ----------------- |
| Previous Day High  | PDH     | প্রধান BSL Target |
| Previous Day Low   | PDL     | প্রধান SSL Target |
| Previous Week High | PWH     | Weekly BSL Target |
| Previous Week Low  | PWL     | Weekly SSL Target |
| Asian Session High | ASH     | London-এর Target  |
| Asian Session Low  | ASL     | London-এর Target  |

---

## Session কীভাবে Liquidity Target করে

```
Liquidity Chain:
1. Asian Session Range তৈরি (ASH/ASL)
2. London Asian H বা L Sweep করে (Liquidity নেয়)
3. London নিজের H/L তৈরি করে
4. NY London-এর H/L Continue বা Sweep করতে পারে
5. পরের দিন: PDH/PDL নতুন Target হয়

Daily Cycle:
PDL/PDH → আজকের Target
ASH/ASL → London-এর Target
London H/L → NY-র Target
```

---

## Session Liquidity Trade করা

### Strategy: PDH/PDL Draw on Liquidity হিসেবে

```
1. Daily Bias চিহ্নিত (Bullish বা Bearish)
2. Bullish হলে: PDH হলো Draw (উপরে Target)
3. Bearish হলে: PDL হলো Draw (নিচে Target)
4. Discount-এ (Bullish) বা Premium-এ (Bearish) Entry খুঁজুন
5. Target: Take Profit হিসেবে PDH/PDL
```
