## FVG কি? (Fair Value Gap) - সম্পূর্ণ ব্যাখ্যা

একটি **FVG** একটি মূল্য অবস্থান যেখানে দ্রুত বিস্থাপন (displacement) কারণে দক্ষতা নেই। এটি প্রকৃতপক্ষে একটি বাজার অদক্ষতা যা মূল্যকে ফিরিয়ে আনতে বাধ্য করে।

### আরও সহজ ভাষায়:

**FVG তৈরি হওয়ার পরিস্থিতি:**
```
পরিস্থিতি ১: স্বাভাবিক ট্রেডিং
ক্রেতা ১: 1.0895 এ ১০ ইউনিট কিনতে চায়
বিক্রেতা ১: 1.0900 এ ১০ ইউনিট বিক্রয় করতে চায়
চুক্তি: 1.0897.5 এ ১০ ইউনিট লেনদেন হয়
→ স্বাভাবিক দাম আবিষ্কার

পরিস্থিতি २: দ্রুত বিস্থাপন (FVG)
বড় খেলোয়াড়: 1.0920 এ ৫০০ ইউনিট কিনতে চায়
কোন বিক্রেতা নেই এই মূল্যে
দাম এক লাফে: 1.0895 → 1.0920 (স্পর্শ ছাড়াই)
→ 1.0895-1.0920 এর মধ্যে কোন লেনদেন হয়নি = FVG
→ মূল্য এই "ফাঁক" ভরতে ফিরে আসবে
```

### Bullish FVG এর প্রয়োজনীয়তা (গভীর):

**তিন ক্যান্ডেল প্যাটার্ন:**
```
Candle 1: 1.0890-1.0900, Close = 1.0900 (ক্রেতা শক্তিশালী)
          ↓
Candle 2: ১.०८८० থেকে ১.०९२० এ দ্রুত গতি (শক্তিশালী বাই)
          ↓
Candle 3: 1.0910-1.0920, Open = 1.0920 (উপরে খোলে!)

চেক করুন: Candle 1 High (1.0900) < Candle 3 Low (1.0910)?
হ্যাঁ! → FVG ঘটেছে!

FVG Zone: 1.0900 থেকে 1.0910 (এই মধ্যে কোন লেনদেন হয়নি)
```

### FVG চার্ট বিশ্লেষণ:

**চার্টে দেখা যাচ্ছে:**
- **Candle 1:** ১.0900 বন্ধ।
- **Candle 2:** শক্তিশালী বাই ক্যান্ডেল
- **Candle 3:** ১.0920 এ খোলা (ফাঁক তৈরি!)
- **Yellow Zone:** ১.0900-১.0920 এর মধ্যে = **FVG** (inefficiency)
- **Blue Line:** দাম আবার FVG অঞ্চলে ফিরে এসেছে = **Price magnet effect**

### Bearish FVG এর প্রয়োজনীয়তা:
```
Candle 1:  Close = 1.0900
Candle 2:  (শক্তিশালী বিক্রয়)
Candle 3:  Open = 1.0880

শর্ত: Candle 1 এর Low > Candle 3 এর High
```

**চার্টে দেখতে:**
```
1.0900 ├─ ← Candle 1 Close
1.0890 │     ↓ এই ফাঁক = FVG
       ├─ ← Candle 3 Open (নিচে লাফ)
1.0880 ┘
```

<Callout type="tip" title="FVG এর বৈশিষ্ট্য">
মূল্য FVG কে "ম্যাগনেট" এর মতো দেখে এবং সেখানে ফিরে আসে রিব্যালেন্স করতে।
</Callout>

## Order Block কি?

একটি **Order Block** সেই ক্যান্ডেল যেখানে প্রতিষ্ঠিত বাণিজ্যীরা বড় পজিশন তৈরি করে।

### Bullish Order Block:
```
দামে ওঠার সময় শক্তিশালী একটি ক্যান্ডেল
↓
বিক্রেতারা চেষ্টা করে ভাঙতে
↓
ব্যর্থ হয় এবং বাউন্স করে উপরে

এই ক্যান্ডেল = Bullish Order Block
```

### Bearish Order Block:
```
দামে নামার সময় শক্তিশালী একটি ক্যান্ডেল
↓
ক্রেতারা চেষ্টা করে ঊর্ধ্বে যেতে
↓
ব্যর্থ হয় এবং ফিরে আসে নিচে

এই ক্যান্ডেল = Bearish Order Block
```

## Order Block বিশ্লেষণ গাইড

### ধরন বুঝুন:
- **বাম পাশ:** Bullish Order Block (প্রাতিষ্ঠানিক ক্রয় জোন)
- **ডান পাশ:** Bearish Order Block (প্রাতিষ্ঠানিক বিক্রয় জোন)

### প্যাটার্ন শনাক্তকরণ:

চার্ট স্পষ্টভাবে দেখায়:
1. **প্রাথমিক শক্তিশালী নড়াচড়া** (নিচে লাল বা উপরে সবুজ)
2. **OB অঞ্চল** হাইলাইট - এখানে প্রতিষ্ঠান অর্ডার পূরণ করেছে
3. **পুনরাবৃত্তি** - মূল্য সংক্ষিপ্ত সময়ের জন্য সরে যায়
4. **পুনরায় পরীক্ষা পর্ব** - দাম OB অঞ্চলে ফিরে আসে
5. **চূড়ান্ত নিশ্চয়করণ** - ক্যান্ডেল প্যাটার্ন প্রবেশের যাচাই করে

**গুরুত্বপূর্ণ:** প্রকৃত শক্তি তখনই আসে যখন OB + FVG + Supply/Demand সব একসাথে মিলে যায় = **বিশাল সংমিশ্রণ**

## FVG এবং Order Block একসাথে

### সবচেয়ে শক্তিশালী সেটআপ

**Order Block এর ভিতরে FVG:**

```
         Bullish OB
         ┌────────┐
         │ ██████ │ ← শক্তিশালী বাই ক্যান্ডেল
1350 ────┤ ██████ │
         │ ██████ │
1340 ────┼────┬───┤
         │    │   │
         │    ↑   │ ← FVG এখানে
1330 ────┼────┴───┤
         │        │
1320 ────┴────────┘
```

**কেন এটি শক্তিশালী?**
1. Order Block = প্রতিষ্ঠিতদের উপস্থিতি
2. FVG = প্রযুক্তিগত শূন্যতা পূরণ করতে হবে
3. একসাথে = উচ্চ সম্ভাবনা রিব্যালেন্স এবং প্রাইস চলা

<Callout type="warning" title="মনে রাখবেন">
FVG এবং Order Block তখনই শক্তিশালী যখন সেগুলি **প্রবণতা দিকে** থাকে।
</Callout>

## সম্পূর্ণ এন্ট্রি সেটআপ

### প্রি-চেক:
1. **উচ্চ টাইমফ্রেমে ট্রেন্ড** (৪ঘন্টা বা দৈনিক) = আপট্রেন্ড
2. **Swing Structure** = উপরের দিকে (HHs and HLs)
3. **কোন CHOCH?** = না, এখনও bullish

### এন্ট্রি জোন খোঁজা:
1. **Order Block চিহ্নিত করুন** = সেই শক্তিশালী বাই ক্যান্ডেল
2. **FVG খোঁজা** = Order Block এর নিচে অন্য কোথাও
3. **দুটি কনফ্লুয়েন্স?** = এন্ট্রি প্রস্তুত

### এন্ট্রি রুল:
```
যখন মূল্য FVG তে প্রবেশ করে:
↓
Bullish ক্যান্ডেল গঠন দেখুন
↓
Candle Close Order Block এর উপরে
↓
ENTER - Bullish OB এর নিচে স্টপ রাখুন
```

## FVG এবং Order Block ব্যর্থতা

### FVG কখনও ধরা হয় না:
```
সম্ভাব্য কারণ:
1. উচ্চ টাইমফ্রেমে কাউন্টারট্রেন্ড চলছে
2. শক্তিশালী সংবাদ প্রকাশ হয়েছে
3. Order Block সত্যিই শক্তিশালী নয় ছিল
→ এন্ট্রি এড়িয়ে যান - পরবর্তী এর জন্য অপেক্ষা করুন
```

### সিগন্যাল ভুল ছিল:
```
এড়ানো:
1. প্রবণতা বিপরীত হয়ে গেল ঠিক আগে
2. Confluence ছিল শুধুমাত্র একটি মাত্র (Order Block বা FVG একটি)
3. রাউন্ড সংখ্যার কাছাকাছি = শব্দ সম্ভাবনা বেশি
```

## পরবর্তী স্তর: Liquidity

FVG এবং Order Block শুধু অর্ধেক গল্প। পরবর্তী ব্লগে আমরা যোগ করব:
- **Liquidity Sweeps** - প্রতিষ্ঠিত ট্রেডাররা কীভাবে ক্ষুদ্র ট্রেডারদের স্তপ কেড়ে নেয়
- **Supply & Demand জোন** - যেখানে প্রকৃত চাহিদা থাকে
