## কেন আপনার একটি চেকলিস্ট দরকার

পেশাদার পাইলট, সার্জন, এবং ইঞ্জিনিয়াররা সবাই চেকলিস্ট ব্যবহার করে — কারণ বিশেষজ্ঞরাও চাপের মধ্যে ভুল করে। ট্রেডিংও এর ব্যতিক্রম নয়। একটি প্রি-ট্রেড চেকলিস্ট:

- **আবেগপূর্ণ এন্ট্রি দূর করে** (FOMO, রিভেঞ্জ, বোরডম)
- **কনফ্লুয়েন্স নিশ্চিত করে** (একক-ফ্যাক্টর ট্রেড নয়)
- **গুণমান মানসম্মত করে** (শুধু A+ সেটআপ পাস করে)
- **ধারাবাহিকতা উন্নত করে** (প্রতিবার একই প্রক্রিয়া)
- **লস কমায়** (খারাপ ট্রেড ফিল্টার হয়ে যায়)

<Callout type="tip" title="পেশাদার মানদণ্ড">
  প্রতিটি Prop Firm ট্রেডার, ইনস্টিটিউশনাল ডেস্ক, এবং হেজ ফান্ডের এক্সিকিউশন প্রোটোকল আছে। আপনার চেকলিস্টই আপনার ট্রেডিং
  সিস্টেমের কার্যকরী রূপ। চেকলিস্ট নেই = ডিসিপ্লিন নেই = ধারাবাহিকতা নেই।
</Callout>

## সম্পূর্ণ প্রি-ট্রেড চেকলিস্ট

### Phase 1: মার্কেট কন্টেক্সট (এন্ট্রি খোঁজার আগে)

```
□ 1. HTF Bias নির্ধারিত?
   - Daily/4H ট্রেন্ড দিক স্পষ্ট (বুলিশ/বিয়ারিশ/রেঞ্জ)
   - রেঞ্জ হলে → ট্রেড করবেন না (বা শুধু রেঞ্জ এজ ট্রেড করুন)
   - "আজ আমি কোন দিকে ট্রেড করছি?"

□ 2. মূল লেভেল মার্ক করা?
   - Previous Day High/Low (PDH/PDL)
   - Previous Week High/Low (PWH/PWL)
   - 4H/Daily Order Blocks
   - গুরুত্বপূর্ণ FVGs
   - Equal Highs/Lows (Liquidity Pools)
   - প্রাইসের কাছে Round Numbers

□ 3. Economic Calendar চেক করা?
   - আগামী 2 ঘন্টায় কোনো High-Impact News?
   - হ্যাঁ হলে: রিলিজের পর পর্যন্ত অপেক্ষা করুন
   - না হলে: স্বাভাবিক কৌশলে এগিয়ে যান

□ 4. সেশন টাইমিং সঠিক?
   - বর্তমানে Kill Zone এ? (London 02:00-05:00 বা NY 08:30-11:00 EST)
   - Kill Zone এর বাইরে → কোনো ট্রেড নয়
   - "আমি কি সঠিক উইন্ডোতে আছি?"
```

### Phase 2: সেটআপ চিহ্নিতকরণ (ট্রেড খোঁজা)

```
□ 5. Liquidity Sweep দেখা গেছে?
   - প্রাইস কি কোনো Key Level নিয়েছে (SSL/BSL)?
   - Sweep = লেভেলের বাইরে Wick + Rejection
   - "Smart Money কি ফুয়েল কালেক্ট করেছে?"

□ 6. Market Structure Shift?
   - LTF (15M/5M) এ CHOCH বা BOS?
   - FVG সহ Displacement?
   - "দিক কি নিশ্চিত হয়েছে?"

□ 7. POI চিহ্নিত?
   - বৈধ Order Block অথবা Fair Value Gap?
   - POI সঠিক Premium/Discount জোনে?
   - First Touch? (3rd/4th টেস্ট নয়)
   - "আমি ঠিক কোথায় এন্ট্রি নিচ্ছি?"

□ 8. Confluence Count (ন্যূনতম 3)?
   - HTF Trend alignment ✓
   - Premium/Discount সঠিক ✓
   - OB বা FVG উপস্থিত ✓
   - Liquidity swept ✓
   - Session timing ✓
   - গণনা: ___ / 5 (≥ 3 প্রয়োজন)
```

### Phase 3: এক্সিকিউশন বিবরণ (ট্রেড নেওয়া)

```
□ 9. Entry Price নির্ধারিত?
   - এন্ট্রির জন্য সুনির্দিষ্ট প্রাইস বা জোন
   - Limit order নাকি Market order প্ল্যান
   - "কোন প্রাইসে আমি এন্ট্রি নিচ্ছি?"

□ 10. Stop Loss বসানো?
   - স্ট্রাকচারাল ইনভ্যালিডেশনের বাইরে
   - অতিরিক্ত টাইট নয় (উইকের জন্য জায়গা)
   - অতিরিক্ত ওয়াইড নয় (যুক্তিসংগত ঝুঁকি)
   - "আমার আইডিয়া কোথায় ভুল?"

□ 11. Take Profit পরিকল্পিত?
   - TP1: নিকটতম লিকুইডিটি/স্ট্রাকচার (ন্যূনতম 1:2)
   - TP2: বর্ধিত টার্গেট (1:3+)
   - Runner: প্রধান লেভেলে ট্রেইল
   - "আমার আইডিয়া কোথায় সম্পূর্ণ?"

□ 12. R:R ক্যালকুলেট করা?
   - ন্যূনতম 1:2 Risk:Reward
   - আদর্শভাবে 1:3 বা তার বেশি
   - 1:2 এর কম → কোনো ট্রেড নয়
   - "এই ট্রেড কি ঝুঁকির মূল্য?"

□ 13. Position Size ক্যালকুলেট করা?
   - ঝুঁকি = অ্যাকাউন্টের সর্বোচ্চ 1%
   - সাইজ = (অ্যাকাউন্ট × ঝুঁকি%) ÷ (স্টপ $ বা পিপ × পিপ ভ্যালু)
   - কখনো অনুমান করবেন না — সর্বদা ক্যালকুলেট করুন
   - "আমি কি সঠিক পরিমাণ ঝুঁকি নিচ্ছি?"
```

### Phase 4: চূড়ান্ত আবেগীয় পরীক্ষা

```
□ 14. আমি কি আবেগীয়ভাবে নিরপেক্ষ?
   - সাম্প্রতিক লস থেকে রাগান্বিত নই (রিভেঞ্জ)
   - সাম্প্রতিক জয় থেকে উত্তেজিত নই (অতি-আত্মবিশ্বাস)
   - বোরড নই (জোর করে ট্রেড)
   - উদ্বিগ্ন নই (FOMO)
   - "একটি ফান্ডেড অ্যাকাউন্টে কি এই ট্রেড নিতাম?"

□ 15. দৈনিক সীমা পূরণ হয়নি?
   - দিনের সর্বোচ্চ ট্রেড সংখ্যার নিচে
   - দৈনিক লস লিমিটের নিচে (3%)
   - ধারাবাহিক লসের কারণে ব্রেক প্রয়োজন নেই
   - "এই ট্রেড নেওয়ার অনুমতি কি আমার আছে?"
```

## দ্রুত ওয়ান-লাইন ভার্সন (প্রিন্ট করুন)

```
প্রতিটি এন্ট্রির আগে নিশ্চিত করুন:
1. HTF Bias? → দিক স্পষ্ট
2. Kill Zone? → সঠিক টাইমিং
3. Liquidity Swept? → ফুয়েল কালেক্টেড
4. Structure Shift? → CHOCH/BOS কনফার্মড
5. POI? → OB/FVG in P&D
6. Confluence ≥ 3? → একাধিক ফ্যাক্টর
7. Stop Defined? → ইনভ্যালিডেশন স্পষ্ট
8. R:R ≥ 1:2? → ঝুঁকির মূল্য
9. Size Calculated? → সর্বোচ্চ 1%
10. Emotional? → নিরপেক্ষ অবস্থা

সব 10 = হ্যাঁ → এক্সিকিউট
যেকোনো = না → স্কিপ
```

## পোস্ট-ট্রেড চেকলিস্ট (সমান গুরুত্বপূর্ণ)

### প্রতিটি ট্রেডের পরে (জয় বা পরাজয়):

```
□ স্ক্রিনশট নেওয়া (এন্ট্রি, এক্সিট, পূর্ণ কন্টেক্সট)
□ R:R রেকর্ড করা (পরিকল্পিত vs প্রকৃত)
□ জার্নাল এন্ট্রি লেখা:
  - সেটআপ কী ছিল?
  - প্রি-ট্রেড চেকলিস্ট মেনেছিল কি?
  - কী ভালো করেছি?
  - কী উন্নতি করতে পারি?
  - ট্রেডের সময় আবেগীয় অবস্থা?
□ ডিসিপ্লিন স্কোর (1-10)
□ ক্যাটাগরি: A+ সেটআপ / B সেটআপ / আবেগীয় ট্রেড

সাপ্তাহিক: সব ট্রেড চেকলিস্টের বিপরীতে রিভিউ
- কতগুলো সব criteria মেনেছে?
- কতগুলো criteria ভঙ্গ করেছে?
- দুইয়ের মধ্যে উইন রেটের পার্থক্য কী?
```

## ট্রেড টাইপ অনুযায়ী চেকলিস্ট

### স্ক্যাল্প (5-15 মিনিট হোল্ড)

```
অপরিহার্য:
□ Kill Zone টাইমিং (শুধু London/NY)
□ 5M CHOCH/BOS কনফার্মড
□ শেষ 5 ক্যান্ডেলের মধ্যে FVG এন্ট্রি
□ স্টপ: LTF স্ট্রাকচারের নিচে (10-15 পিপ)
□ টার্গেট: পরবর্তী LTF লিকুইডিটি (ন্যূনতম 1:2)
□ সময়সীমা: 30 মিনিটে হিট না হলে → ক্লোজ/ট্রেইল
```

### ইন্ট্রাডে (1-4 ঘন্টা হোল্ড)

```
অপরিহার্য:
□ 4H bias aligned
□ 15M এন্ট্রি কনফার্মেশন (CHOCH + FVG/OB)
□ সেশন লেভেলে Sweep (Asian/London H/L)
□ স্টপ: 15M স্ট্রাকচারের বাইরে
□ টার্গেট: সেশন হাই/লো বা PDH/PDL
□ ম্যানেজ: 1:2 তে পার্শিয়াল, বাকি ট্রেইল
```

### সুইং (1-5 দিন হোল্ড)

```
অপরিহার্য:
□ Daily/Weekly bias aligned
□ 4H এন্ট্রি কনফার্মেশন
□ প্রধান লিকুইডিটি সুইপড (Weekly/Monthly লেভেল)
□ স্টপ: 4H স্ট্রাকচারের বাইরে (ওয়াইডার গ্রহণযোগ্য)
□ টার্গেট: পরবর্তী সাপ্তাহিক লেভেল
□ ধৈর্য: ট্রেডকে সেশনগুলোতে ডেভেলপ হতে দিন
□ Daily স্ট্রাকচারের সাথে ট্রেইল (ইন্ট্রাডে নয়েজ নয়)
```

## সাধারণ এক্সিকিউশন ভুল

<Callout type="warning" title="এগুলো আপনার এজ ভাঙে">

**1. চেকলিস্ট স্কিপ করা** — "আমি জানি এটি একটি ভালো ট্রেড" → সাধারণত ভালো হয় না।

**2. কনফার্মেশনের আগে এন্ট্রি** — কনফার্ম না করে অনুমান করা = জুয়া।

**3. এন্ট্রির পরে স্টপ সরানো** — খুব টাইট মনে হলো → লস আরো বড় হয়।

**4. টেক প্রফিট প্ল্যান নেই** — আরো বেশির আশায় ধরে থাকা → লাভ ফেরত দেওয়া।

**5. ওভার-সাইজিং** — "এটি বিশেষ" → এটি নয়। প্রতিবার একই 1%।

**6. জার্নালিং না করা** — যা ট্র্যাক করেন না তা উন্নত করতে পারবেন না।

**7. Kill Zone এর বাইরে ট্রেডিং** — Asian সেশনে বোরডম-চালিত এন্ট্রি।

</Callout>

## আপনার ব্যক্তিগত চেকলিস্ট তৈরি করুন

```
ধাপ 1: এই টেমপ্লেট দিয়ে শুরু করুন
ধাপ 2: 30 ট্রেডের পর রিভিউ করুন:
  - কোন criteria আপনাকে খারাপ ট্রেড থেকে বাঁচিয়েছে?
  - কোন criteria আপনি বারবার ভঙ্গ করছেন?
  - যেকোনো ব্যক্তিগত নিয়ম যোগ করুন (নির্দিষ্ট পেয়ার, সেশন)
ধাপ 3: আপনার অপরিহার্য criteria তে সরলীকৃত করুন
ধাপ 4: প্রিন্ট করুন, মনিটরের পাশে রাখুন
ধাপ 5: কখনো এমন ট্রেড নিবেন না যা পাস করে না

আপনার চেকলিস্ট হওয়া উচিত:
- একটি পেজে (বা স্ক্রিনে) ফিট হওয়া
- 60 সেকেন্ডের কমে সম্পূর্ণ হওয়া
- বাইনারি (হ্যাঁ/না, "হয়তো" নয়)
- আপোষহীন (কোনো ব্যতিক্রম নেই)
```
