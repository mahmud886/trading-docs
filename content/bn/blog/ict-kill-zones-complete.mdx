## ICT কি? (Institutional Client Terminal)

**ICT** একটি উন্নত ট্রেডিং পদ্ধতি যা **সময়**, **মার্কেট স্ট্রাকচার**, এবং **প্রতিষ্ঠিত আচরণ** একসাথে ব্যবহার করে।

মূল ধারণা: প্রতিষ্ঠিত ট্রেডাররা নির্দিষ্ট সময়ে নির্দিষ্ট কাজ করে। তাদের প্রবেশ সময় শিখুন।

---

## Kill Zone কি?

একটি **Kill Zone** একটি নির্দিষ্ট সময়কাল যখন বাজার সবচেয়ে প্রাণবন্ত থাকে এবং প্রতিষ্ঠিত ব্যাপক নড়াচড়া করে।

### Kill Zone এর প্রকার:

```
1. ইউরোপীয় সেশন Kill Zone (ইউরোপীয়)
   সময়: 08:00-10:00 বিকাল (BD সময়)
   ট্রিগার: লন্ডন ওপেন

२. নিউইয়র্ক সেশন Kill Zone (আমেরিকান)
   সময়: 08:30 রাত - 10:30 রাত (BD সময়)
   ট্রিগার: নিউইয়র্ক ওপেন

३. এশীয় সেশন Kill Zone (টোকিও)
   সময়: 08:00-10:00 সকাল (BD সময়)
   ট্রিগার: টোকিও ওপেন
```

```

```

## Kill Zone Strategy

### মৌলিক নিয়ম:

```
Rule 1: Kill Zone তে এন্ট্রি করুন
        কখনও আগে নয়, কখনও দেরিতে নয়

Rule 2: Expansion দেখুন (বড় ক্যান্ডেল)
        এটি প্রতিষ্ঠিত সক্রিয় লক্ষণ

Rule 3: Break FVG বা Order Block
        প্রতিষ্ঠিত তাদের স্টপ সংগ্রহ করছে

Rule 4: Momentum স্কোর করুন
        বাজার দ্রুত চলছে = Kill Zone সক্রিয়
```

### Kill Zone এন্ট্রি চেকলিস্ট:

```
☐ সঠিক সময়কাল? (Kill Zone ঘন্টা)

☐ PD Array চিহ্নিত?
☐ FVG বা OB আছে?
☐ প্রথম ঘন্টায় Expansion?
☐ CHOCH বা BOS দেখা গেছে?
```
