## OTE (Optimal Trade Entry) কী?

**Optimal Trade Entry (OTE)** হলো ICT কনসেপ্ট যা রিট্রেসমেন্টের মধ্যে সর্বোচ্চ-প্রোবাবিলিটি এন্ট্রি জোন চিহ্নিত করে। এটি **61.8% ও 78.6% Fibonacci retracement** লেভেলের মাঝে বসে — সুইট স্পট যেখানে ইনস্টিটিউশনাল অর্ডার ক্লাস্টার করে।

<Callout type="info" title="OTE কেন কাজ করে">
  ইম্পালসিভ মুভের পর প্রাইস রিট্রেস করলে, ইনস্টিটিউশন 61.8-78.6% জোনে অর্ডার রাখে। এই জোন সেরা ব্যালেন্স দেয়: -
  **কনফার্মেশন** (যথেষ্ট রিট্রেসমেন্ট হয়েছে) - **রিস্ক** (স্টপ এখনো টাইট — 100% লেভেলের ওপারে) - **রিওয়ার্ড**
  (দুর্দান্ত R:R এর জন্য যথেষ্ট গভীরে এন্ট্রি)
</Callout>

## Fibonacci রিট্রেসমেন্ট মূলকথা

### মূল Fibonacci লেভেল:

| লেভেল | নাম              | গুরুত্ব              |
| ----- | ---------------- | -------------------- |
| 0%    | সুইং এক্সট্রিম   | রিট্রেসমেন্ট শুরু    |
| 23.6% | শ্যালো           | এন্ট্রির জন্য খুব কম |
| 38.2% | স্ট্যান্ডার্ড    | ন্যূনতম রিট্রেসমেন্ট |
| 50%   | ইক্যুইলিব্রিয়াম | মিডপয়েন্ট           |
| 61.8% | গোল্ডেন রেশিও    | **OTE জোন শুরু**     |
| 70.5% | ICT সুইট স্পট    | **প্রাইম OTE লেভেল** |
| 78.6% | ডিপ              | **OTE জোন শেষ**      |
| 100%  | ফুল রিট্রেস      | ইনভ্যালিডেশন লেভেল   |

### Fibonacci কীভাবে আঁকবেন:

**বুলিশ OTE (আপট্রেন্ডে পুলব্যাক কেনা):**

- **সুইং LOW** থেকে **সুইং HIGH** পর্যন্ত আঁকুন
- তাদের মধ্যে 61.8-78.6% জোন = OTE (বাই জোন)

**বিয়ারিশ OTE (ডাউনট্রেন্ডে পুলব্যাক বিক্রি):**

- **সুইং HIGH** থেকে **সুইং LOW** পর্যন্ত আঁকুন
- তাদের মধ্যে 61.8-78.6% জোন = OTE (সেল জোন)

## OTE + Order Block = সর্বোচ্চ কনফ্লুয়েন্স

সবচেয়ে শক্তিশালী ICT সেটআপ হলো যখন **OTE জোনের মধ্যে Order Block** থাকে:

1. প্রাইস ইম্পালসিভ মুভ করে (expansion leg)
2. সেই leg-এ OB চিহ্নিত করুন
3. সুইং লো থেকে হাই পর্যন্ত Fibonacci আঁকুন
4. OB যদি 61.8-78.6% রিট্রেসমেন্টের মধ্যে পড়ে → **সর্বোচ্চ কনফ্লুয়েন্স**

```
এই OB-in-OTE সেটআপ দেয়:
✓ ইনস্টিটিউশনাল অর্ডার ফ্লো ব্যাকিং (OB)
✓ গাণিতিক প্রোবাবিলিটি (Fibonacci)
✓ অপটিমাল রিস্ক প্লেসমেন্ট (OTE-এর ওপারে স্টপ)
✓ চমৎকার R:R (রিট্রেসমেন্টে গভীরে এন্ট্রি)
```

## সম্পূর্ণ OTE ট্রেডিং কৌশল

### ধাপে ধাপে:

1. **HTF ট্রেন্ড দিক চিহ্নিত** (Daily/4H)
2. **Expansion Leg এর অপেক্ষা** (ট্রেন্ড দিকে ডিসপ্লেসমেন্ট সহ ইম্পালসিভ মুভ)
3. Expansion leg-এ **Fibonacci আঁকুন**
4. **OTE Zone মার্ক** (61.8-78.6%)
5. **OTE-তে কনফ্লুয়েন্স খুঁজুন** — OB? FVG? স্ট্রাকচার লেভেল?
6. OTE জোনে **রিট্রেস** এর অপেক্ষা
7. **LTF কনফার্মেশনে এন্ট্রি** (15M/5M CHOCH at OTE)
8. **স্টপ:** 100% লেভেলের ওপারে
9. **টার্গেট:** -27% বা -62% Fibonacci extension

## টার্গেটের জন্য Fibonacci Extension

| Extension লেভেল | ব্যবহার                               |
| --------------- | ------------------------------------- |
| -27% (1.272)    | **কনজার্ভেটিভ** — প্রথম TP            |
| -62% (1.618)    | **স্ট্যান্ডার্ড** — মূল TP            |
| -100% (2.0)     | **অ্যাগ্রেসিভ** — রানার               |
| -162% (2.618)   | **এক্সট্রিম** — বিরল কিন্তু শক্তিশালী |

## OTE ইনভ্যালিডেশন

OTE সেটআপ **ইনভ্যালিড** হয় যখন:

1. **100% এর ওপারে প্রাইস ক্লোজ** — ফুল সুইং রিট্রেস হলে OTE ইনভ্যালিড
2. **OTE-তে LTF কনফার্মেশন নেই** — CHOCH/MSS না দেখালে এন্ট্রি নেই
3. **আপনার বিরুদ্ধে স্ট্রাকচার ব্রেক** — HTF স্ট্রাকচার শিফট
4. **Kill Zone শেষ** — Kill Zone-এর বাইরে OTE = কম প্রোবাবিলিটি

## সাধারণ ভুল

<Callout type="warning" title="এড়িয়ে চলুন">

**❌ ভুল সুইং-এ Fib আঁকা** — সবচেয়ে সাম্প্রতিক ও প্রাসঙ্গিক expansion leg ব্যবহার করুন।

**❌ 38.2% বা 50%-এ এন্ট্রি** — এগুলো খুব শ্যালো। ইনস্টিটিউশনাল সুইট স্পট 61.8-78.6%। ধৈর্য ধরুন।

**❌ OTE-তে কনফ্লুয়েন্স ছাড়া** — OTE একা যথেষ্ট নয়। OB, FVG বা স্ট্রাকচার লেভেলও দরকার।

**❌ LTF কনফার্মেশন ছাড়া এন্ট্রি** — OTE-তে অন্ধভাবে লিমিট অর্ডার দেবেন না।

**❌ OTE-এর মধ্যে খুব টাইট স্টপ** — স্টপ 100% লেভেলের ওপারে হতে হবে।
