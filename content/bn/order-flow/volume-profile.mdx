## Volume Profile কী?

**Volume Profile** Volume কে পাশ ফিরিয়ে দেয়: **সময়ের** বারে Volume এর বদলে একটি সময়কালে প্রতিটি **প্রাইসে** যে Volume ট্রেড হয়েছে তা দেখায়। এটা উত্তর দেয় _কোথায় ট্রেডিং গৃহীত হয়েছে আর কোথায় প্রাইস দ্রুত ভেদ করে গেছে?_

<Callout type="warning" title="সুর নরম করা হয়েছে">
  মূল লেসনে বলা ছিল প্রতিষ্ঠান "সময়-ভিত্তিক Volume এর পরোয়া করে না" আর প্রোফাইল তারা কোথায় অর্ডার ফিল করেছে "ঠিক তাই
  দেখায়"। প্রোফাইল দেখায় **কোথায় Volume ট্রেড হয়েছে**, কে করেছে তা নয়। আর POC নিয়ম করে "চুম্বকের মতো কাজ করে" না —
  প্রাইস প্রায়ই ফেরে, আবার প্রায়ই ফেরে না।
</Callout>

  প্রোফাইল প্রাইসে ট্রেড-বাই-ট্রেড Volume ব্যবহার করে।

| উপাদান                   | সংজ্ঞা                                                      | চার্টে                         |
| ------------------------ | ----------------------------------------------------------- | ------------------------------ |
| **POC** Point of Control | সর্বোচ্চ Volume এর প্রাইস                                   | 1.0874                         |
| **Value Area (VA)**      | POC এর চারপাশে ৭০% Volume ধারণকারী সংলগ্ন এলাকা             | 1.0858 – 1.0879                |
| **VAH / VAL**            | Value Area এর উপর ও নিচ                                     | 1.0879 / 1.0858                |
| **HVN** High-Volume Node | Volume এর গুচ্ছ: প্রাইস এখানে সময় কাটিয়েছে ও ট্রেড হয়েছে | 1.0858 আর 1.0874               |
| **LVN** Low-Volume Node  | পাতলা এলাকা: প্রাইস দ্রুত ভেদ করে গেছে                      | 1.0867 (POC এর Volume এর ≈ ৫%) |

৭০% Value Area **POC থেকে বাইরের দিকে** গড়া হয়, প্রতিবার বেশি Volume এর প্রতিবেশী প্রাইস যোগ করে। এই সেশনের মতো দুই-Node এর সেশনে এলাকা দুটিকেই ছোঁয় — আর LVN এর মাঝখানে পড়ে। তাই Value Area এর পাশাপাশি LVN আর HVN গুরুত্বপূর্ণ।

## আকার কী ইঙ্গিত দেয়

| প্রোফাইলের আকার                         | প্রায়ই বর্ণনা করে                  | সাধারণ ধারণা                                 |
| --------------------------------------- | ----------------------------------- | -------------------------------------------- |
| **একটি ফোলা (D-আকার)**                  | ভারসাম্যপূর্ণ সেশন                  | প্রাইস POC এর চারপাশে ঘোরে                   |
| **দুটি ফোলা (b / Double Distribution)** | নতুন এলাকায় যাওয়া, এই চার্টের মতো | LVN দুই গৃহীত এলাকার মাঝে একটি "দ্রুত" এলাকা |
| **এক প্রান্তে পাতলা লেজ**               | ওই প্রাইসগুলো প্রত্যাখ্যাত          | প্রাইস সেখানে গিয়ে ফিরে এসেছে               |

এগুলো যা ঘটেছে তার বর্ণনা, আর আকার শুধু ইঙ্গিত দেয় পরে কী হতে পারে।

## প্রোফাইল লেভেল ব্যবহার

| লেভেল         | সাধারণ ব্যবহার                                                    | সতর্কতা                                        |
| ------------- | ----------------------------------------------------------------- | ---------------------------------------------- |
| **POC**       | ন্যায্য-মূল্যের রেফারেন্স; Mean Reversion এর টার্গেট              | প্রাইস সারাদিন POC থেকে দূরে ট্রেন্ড করতে পারে |
| **VAH / VAL** | গৃহীত মূল্যের প্রান্ত; টেস্ট ও হোল্ডে এন্ট্রি, বা Breakout        | Tape দিয়ে টেস্ট করুন; ওয়াল ধরবেন না          |
| **HVN**       | প্রাইস এর চারপাশে ধীর, ঘুরে বা আটকে যেতে চায়                     | শক্তিশালী মুভ HVN ভেদ করে চলে যেতে পারে        |
| **LVN**       | প্রাইস দ্রুত ভেদ করতে চায়; Stop/টার্গেটের রেফারেন্স হিসেবে কাজের | LVN এও দ্রুত মুভ উল্টাতে পারে                  |

### উদাহরণ (চার্ট ছাড়া) — LVN টার্গেট ও Stop রেফারেন্স হিসেবে

চার্টে প্রাইস **1.0874** এর কাছে উপরের HVN এর চারপাশে ঘুরেছে আর **1.0872** এ নেমে এসেছে। পরিকল্পনা: **1.0873** এ POC হোল্ডে Buy, Stop **1.0866** (LVN এর ঠিক নিচে, কারণ এলাকা হারালে প্রাইস পাতলা অঞ্চলে পড়ে যেতে পারে), টার্গেট **1.0885** (সেশন High এর উপরে): রিস্ক ৭, রিওয়ার্ড ১২, পরিকল্পিত **১ : ১.৭**। **1.0867** এর নিচে Close হলে উপরের এলাকা প্রত্যাখ্যাত আর নিচের পাতলা অঞ্চল খোলা।

## কোন প্রোফাইল?

| প্রোফাইল                  | সময়কাল              | ব্যবহার                              |
| ------------------------- | -------------------- | ------------------------------------ |
| **সেশন প্রোফাইল**         | এক ট্রেডিং দিন       | আজকের POC, VA আর Node                |
| **Composite / সাপ্তাহিক** | কয়েক দিন বা সপ্তাহ  | দীর্ঘমেয়াদি মূল্য আর Node           |
| **Fixed Range**           | বাছাই করা Swing থেকে | মুভের পর ট্রেডিং কোথায় গৃহীত হয়েছে |

আগের দিনের POC, VAH আর VAL পরের দিনের জনপ্রিয় রেফারেন্স। কোন প্রোফাইল বিশ্বাস করবেন তা নিজের মার্কেটে পরীক্ষার বিষয়।

## সাধারণ ভুল

| ভুল                                            | সমাধান                                         |
| ---------------------------------------------- | ---------------------------------------------- |
| POC কে চুম্বক ধরা                              | এটা রেফারেন্স; না টিকলেও পরিকল্পনা রাখুন       |
| Tick Volume কে এক্সচেঞ্জ Volume এর মতো ব্যবহার | ফিউচার্স বা আসল-Volume মার্কেট বেছে নিন        |
| সময়কাল উপেক্ষা                                | একই প্রাইসের ভিন্ন সময়কালে ভিন্ন প্রোফাইল     |
| প্রতিটি Node এ ট্রেড                           | Structure, সেশন আর Stop এর সাথে মেলান          |
| Value Area সংলগ্ন তা ভুলে যাওয়া               | দুই-Node এর সেশনে VA এর ভেতরে পাতলা অঞ্চল থাকে |

## অনুশীলন

1. একটি ফিউচার্স চার্টে গতকালের সেশনের প্রোফাইল বানান। POC, VAH, VAL আর মূল Node চিহ্নিত করুন।
2. আজকের প্রাইস Value Area এর তুলনায় কোথায় খুলেছে আর VAH/VAL এ কী করেছে লিখুন।
3. একটি LVN চিহ্নিত করুন আর প্রাইস সেটা পার হওয়ার সময় কেমন আচরণ করেছে দেখুন।
4. আপনার [ট্রেডিং জার্নালে](/bn/tools/journal-template) লিখুন।
