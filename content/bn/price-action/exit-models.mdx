## Exit Strategy গুরুত্বপূর্ণ

Exit আপনার **প্রকৃত Profit** নির্ধারণ করে। Perfect Entry-র সাথে খারাপ Exit = মাঝারি ফলাফল।

---

## Exit-এর ধরন

### ১. Fixed Target

- পরবর্তী S/R Level
- Measured Move (Pattern Height)
- Fibonacci Extension (127.2%, 161.8%)
- Risk Multiple (সবসময় 2R বা 3R)

### ২. Structural Exit

- পরবর্তী Opposing Swing High/Low
- বিপরীত Order Block
- Liquidity Pool (Equal H/L)
- Previous Session H/L

### ৩. Trailing Stop

- প্রতিটি নতুন Swing Point-এর পিছনে
- 20 EMA-এর পিছনে
- ATR-based (1.5× ATR Distance)
- 1R-এর পর Break-even

### ৪. Partial Exit (Scaling Out)

- 1:1 R:R-এ ৫০% → SL BE-তে
- 1:2 R:R-এ ৩০%
- চূড়ান্ত Target-এ ২০% Trailing

### ৫. Time-Based

- Session শেষ (Intraday)
- Entry-র ২৪-৪৮ ঘণ্টা পর (Swing)
- স্থবির Trade খুব কমই Winner হয়

---

## Style সুপারিশ

| Style    | সেরা Exit               |
| -------- | ----------------------- |
| Scalping | Fixed Target (5-20 Pip) |
| Intraday | Structural + Time       |
| Swing    | Partial + Trailing      |
| Position | Structural + Trailing   |

---

## Exit নিয়ম

1. Entry-র আগে Exit পরিকল্পনা
2. TP আরো দূরে সরাবেন না
3. Partial Profit চাপ কমায়
4. Opposing Level সম্মান করুন
5. স্থবির Trade-এ Time Stop কাজ করে
