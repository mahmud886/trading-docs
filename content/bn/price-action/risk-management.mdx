## ১-২% নিয়ম

একটি ট্রেডে কখনো অ্যাকাউন্টের ১-২% এর বেশি রিস্ক নেবেন না।

```
পজিশন সাইজ = (অ্যাকাউন্ট × রিস্ক %) / (এন্ট্রি - SL)

উদাহরণ: $10,000 অ্যাকাউন্ট, ১% রিস্ক, ২০-পিপ SL
পজিশন = ($10,000 × 0.01) / 20 = $5/পিপ = 0.5 লট
```

## প্রাইস অ্যাকশনে SL প্লেসমেন্ট

| সেটআপ | SL প্লেসমেন্ট |
|-------|--------------|
| **পিন বার** | পিন বারের উইকের বাইরে |
| **এনগালফিং** | এনগালফিং ক্যান্ডেলের রেঞ্জের বাইরে |
| **ব্রেকআউট** | ব্রেকআউট লেভেলের নিচে (বাই) |
| **পুলব্যাক** | পুলব্যাক লো এর নিচে (বাই) |
| **সাপোর্ট বাউন্স** | সাপোর্ট জোন + বাফার এর নিচে |

### বাফার নিয়ম
- Forex: ৫-১০ পিপ
- Gold: ৫০-১০০ পিপ
- ইনডিসেস: ১০-২০ পয়েন্ট
