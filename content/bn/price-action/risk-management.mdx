## PA Trader-দের জন্য Risk Management

Price Action Trading-এ Risk Management **Structural Stop Placement** ব্যবহার করে — Stop যথেচ্ছ Pip Distance-এর বদলে Swing Point, Order Block বা Liquidity Level-এর বাইরে যায়।

---

## Stop Loss Placement নিয়ম

| Setup Type        | Stop অবস্থান                  |
| ----------------- | ----------------------------- |
| Order Block Entry | OB-এর বাইরে (Body)            |
| Fibonacci Entry   | 78.6% বা Swing Point-এর বাইরে |
| S/R Bounce        | Zone-এর বাইরে + Buffer        |
| Trendline Bounce  | Trendline-এর বাইরে            |
| CHOCH Entry       | CHOCH Swing Point-এর বাইরে    |
| Liquidity Sweep   | Sweep Wick-এর বাইরে           |

## Position Sizing সূত্র

```
Lot Size = (Account × Risk%) ÷ (Stop Loss Pip × Pip Value)

উদাহরণ:
- Account: $10,000
- Risk: 1% = $100
- Stop: Structure-based = 35 Pip
- Pip Value: $10 (Standard Lot)
- Lot Size: $100 ÷ (35 × $10) = 0.29 Lot
```

## Price Action-এর জন্য Risk নিয়ম

1. **প্রতি Trade-এ সর্বোচ্চ ১-২%** — আলোচনাযোগ্য নয়
2. **Structure-এর বাইরে Stop** — Structure-তে নয় (Buffer দিন)
3. **চওড়া Stop = ছোট Position** (Stop না দেওয়া নয়)
4. **সর্বোচ্চ ৩ Correlated Position** — EUR/USD + GBP/USD = Correlated
5. **দৈনিক Loss Limit: 3%** — দিনের জন্য Trading বন্ধ
6. **সাপ্তাহিক Loss Limit: 5%** — পরবর্তী সপ্তাহে Size কমান
7. **Max Drawdown: 10%** — সম্পূর্ণ Strategy Review

## Structural vs. Fixed Stop

| পদ্ধতি     | বর্ণনা                 | সুবিধা                    | অসুবিধা                     |
| ---------- | ---------------------- | ------------------------- | --------------------------- |
| Structural | Swing/OB/Zone-এর বাইরে | যৌক্তিক, কম Random SL Hit | কখনো চওড়া                  |
| Fixed Pip  | সবসময় X Pip           | সহজ, ধারাবাহিক Size       | Structure-এর ভিতরে হতে পারে |
| ATR-based  | 1.5-2× ATR             | Volatility-adjusted       | Structure সম্মান করে না     |

**সেরা পদ্ধতি: Structural Stop, তারপর Risk%-এ মানানসই Position Size গণনা।**
