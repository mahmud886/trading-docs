## Intraday Trading কী?

Intraday Trading মানে **একই Trading Day-এ** সব Position Open ও Close করা। M15-H1-এ Price Action ব্যবহার করে, High-volume Session-এ (Kill Zone) ৩০-১০০ Pip Move Trade করা।

<Callout type="info" title="Intraday Edge">
Intraday Trading Overnight Risk দূর করে এবং দৈনিক Income Potential দেয়। Session Analysis ও Higher-timeframe Bias-এর সাথে একত্রে পুনরাবৃত্তিযোগ্য সুযোগ দেয়।
</Callout>

|-----------|-----------|--------|

| **London Close** | 10:00-12:00 PM | Profit-taking |

## Daily Bias নির্ধারণ

```
1. D1 Candle Direction (Bullish/Bearish)
2. H4 Structure (HH/HL বা LH/LL)
3. D1 Level-এর তুলনায় Price অবস্থান
4. আগের Session আচরণ

Bias = আজ সম্ভবত কোন Direction
শুধু Bias-এর সাথে Aligned Trade নিন।
```

## Intraday Entry পদ্ধতি

### Session High/Low Sweep:
1. পূর্ববর্তী Session Range চিহ্নিত (Asian H/L)
2. নতুন Session এক দিক Sweep করার অপেক্ষা
3. Sweep-এর পর Reversal-এ Enter
4. Stop: Sweep Wick-এর বাইরে
5. Target: বিপরীত Session Extreme

### Bias + Order Block:
1. Daily Bias নির্ধারণ
2. Bias-এর সাথে Aligned H1 OB Mark
3. Kill Zone-এ OB-তে Pullback-এর অপেক্ষা
4. M15 Confirmation-এ Enter
5. Target: D1 Key Level বা Daily Extreme
