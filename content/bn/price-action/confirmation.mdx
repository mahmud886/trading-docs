## Confirmation কী?

Confirmation হলো Entry-র আগে Trade Idea Validate করে এমন **অতিরিক্ত প্রমাণ**। High-probability Trade-কে Gamble থেকে আলাদা করে।

---

## Confirmation-এর ধরন

### ১. Candlestick Confirmation

- Bullish: Engulfing, Hammer, Morning Star, Inside Bar Break Up
- Bearish: Engulfing, Shooting Star, Evening Star, Inside Bar Break Down
- Candle CLOSE অপেক্ষা করুন — Wick ধোঁকা দিতে পারে

### ২. Structural Confirmation (LTF)

```
HTF Zone-এ পৌঁছে LTF-এ নামুন এবং খুঁজুন:
- আপনার Trade Direction-এ CHOCH
- Momentum Shift Confirm করে BOS
- LTF Order Block Respect

উদাহরণ:
H4 Zone পৌঁছেছে → M15 Bullish CHOCH দেখায় → CONFIRMED
```

### ৩. Volume Confirmation

- High-volume Rejection = শক্তিশালী
- High-volume Breakout = সত্যিকার
- Low-volume Break = সম্ভবত Fakeout

### ৪. Multi-Timeframe Confirmation

```
সবচেয়ে শক্তিশালী: সব Timeframe একমত
D1: Bullish ✓
H4: Key Level-এ ✓
H1: CHOCH তৈরি হচ্ছে ✓
M15: Entry Pattern ✓
= সর্বোচ্চ CONFIDENCE
```

---

## নিয়ম

1. কমপক্ষে ১ Confirmation ছাড়া কখনো Enter নয় (২ পছন্দনীয়)
2. HTF Confirmation > LTF Confirmation
3. Structural > Candlestick
4. Volume Conviction Confirm করে
5. ধৈর্য — Move মিস হলেও অপেক্ষা
6. False Confirmation আছে — সবসময় Stop ব্যবহার
