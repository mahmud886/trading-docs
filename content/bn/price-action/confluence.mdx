## Confluence কী?

**Confluence** হলো যখন ট্রেড করার কয়েকটি **স্বাধীন** কারণ **একই প্রাইসে** এসে মেলে। একটি লেভেল একটি অনুমান; একই প্রাইসে তিনটি সম্পর্কহীন কারণ একটি Zone কে দেখার মতো করে তোলে।

মূল শব্দ **স্বাধীন**। একই Close থেকে তৈরি দুটি ইন্ডিকেটর (যেমন RSI আর Stochastic) একটি কারণ, দুবার গোনা।

<Callout type="warning" title="সরানো হয়েছে: আত্মবিশ্বাসের শতাংশ">
  মূল লেসনে বলা ছিল একটি লেভেল "~৫০%", Fibonacci যোগে "~৬৫%", Order Block "~৭৫%" আর ট্রেন্ডের মিল "~৮৫%"। এই সংখ্যাগুলোর
  উৎস নেই। Confluence সেটআপকে ভালো করে; এটা কোনো জানা সম্ভাবনা দেয় না।
</Callout>

## Confluence ফ্যাক্টর

| গ্রুপ                | ফ্যাক্টর                                         | কী খুঁজবেন                                       |
| -------------------- | ------------------------------------------------ | ------------------------------------------------ |
| **Structure**        | Support/Resistance, Flipped লেভেল                | কয়েকটি পরিষ্কার রিঅ্যাকশন; ভাঙা লেভেলের Retest  |
|                      | আগের দিন/সপ্তাহের High বা Low                    | যে লেভেল অনেক ট্রেডার দেখেন                      |
|                      | Equal Highs/Lows                                 | তার ওপারে জমে থাকা Liquidity                     |
|                      | Round Number                                     | 1.0850, 1.1000, 2,400                            |
| **Fibonacci**        | সর্বশেষ Impulse এর 50%, 61.8%, 78.6% Retracement | পরিষ্কার Swing Low থেকে Swing High পর্যন্ত আঁকুন |
| **Order Flow (SMC)** | Order Block, FVG, Breaker                        | দেখুন [SMC সেকশন](/bn/smc/supply-demand-zones)   |
| **Timeframe**        | HTF ট্রেন্ড আর HTF লেভেল                         | ট্রেড Daily/H4 ছবির সাথে মেলে                    |

## একটি সহজ চেকলিস্ট

"Confidence Score" এর বদলে **বাধ্যতামূলক** আর **অতিরিক্ত** আইটেমসহ একটি চেকলিস্ট ব্যবহার করুন:

| বাধ্যতামূলক (সবগুলো)                      | অতিরিক্ত (গুনুন)                  |
| ----------------------------------------- | --------------------------------- |
| HTF ট্রেন্ড বা HTF লেভেল দিককে সমর্থন করে | Zone এর ভেতরে Fibonacci 50–78.6%  |
| Zone এ একটি পরিষ্কার Structural লেভেল     | Zone এর ভেতরে Round Number        |
| আপনার রিস্ক নিয়মে মানানসই Stop           | Zone এর ভেতরে Order Block / FVG   |
| R:R অন্তত আপনার ন্যূনতম (যেমন ১ : ২)      | Zone এর ঠিক ওপারে Liquidity Sweep |

একটি বাধ্যতামূলক আইটেম না থাকলে = ট্রেড নেই, যত অতিরিক্তই থাকুক। পাস করা প্রতিটি ট্রেডে পজিশন সাইজ **একই** রাখুন; সেটআপ "পারফেক্ট দেখাচ্ছে" বলে সাইজ বাড়াবেন না।

### উদাহরণ (চার্ট ছাড়া) — Confluence Zone এ Gold Short

Gold এর Daily ট্রেন্ড Down। একটি র‍্যালি **2,420 – 2,425** এ পৌঁছায়, যেখানে একটি ভাঙা Support (এখন Resistance), শেষ Down-Leg এর 61.8% Retracement (**2,421**) আর 2,425 এর আগের দিনের High মিলে যায়। **2,420** এ Sell, Stop **2,428**, টার্গেট **2,388**: রিস্ক $8, রিওয়ার্ড $32, পরিকল্পিত **১ : ৪.০** — আগে একটি Confirmation ক্যান্ডেল বাধ্যতামূলক ([Confirmation](/bn/price-action/confirmation) দেখুন)।

## অনুশীলন

1. অতীতের ১০টি চার্টে শেষ Impulse আর তার 50/61.8/78.6% লেভেল চিহ্নিত করুন।
2. Structural লেভেল আর Round Number চিহ্নিত করুন। শুধু সেই Zone গুলো বৃত্ত করুন যেখানে ৩+ স্বাধীন ফ্যাক্টর ~১৫ পিপ (Forex) বা ~$5 (Gold) এর মধ্যে মেলে।
3. প্রতিটি Zone এ কী হয়েছে লিখুন — আর শুধু একটি ফ্যাক্টরের Zone গুলোতেও।
4. আপনার [ট্রেডিং জার্নালে](/bn/tools/journal-template) লিখুন।
