## Value-Area Migration কী?

প্রতিদিনের [Market Profile](/bn/auction-market/market-profile) এ একটি **Value Area** (যে রেঞ্জে দিনের প্রায় ৭০% TPO) আর একটি **Point of Control (POC)** থাকে। **Migration** হলো এগুলো দিন থেকে দিনে কীভাবে সরে: নতুন Value Area আগেরটির সাথে ওভারল্যাপ করতে পারে, উপরে থাকতে পারে, বা নিচে থাকতে পারে।

<Callout type="warning" title="সংশোধিত ও নরম করা হয়েছে">
  মূল লেসনে বলা হয়েছিল Migration "প্রাতিষ্ঠানিক Accumulation, Distribution ও দিকনির্দেশনা" প্রকাশ করে এবং
  "প্রাতিষ্ঠানিক ফ্লো" ট্র্যাক করে। Value Area দেখায় **সময়** কোথায় কেটেছে, কে বা কেন কাটিয়েছে তা নয়। Migration হলো
  কোথায় ট্রেড গৃহীত হয়েছে তার বর্ণনা; তা চলতে থাকবে কি না সেটি আলাদা প্রশ্ন।
</Callout>

## তিন ধরনের সম্পর্ক

| আজকের Value বনাম গতকালের | প্রায়ই যেভাবে বলা হয় | যে প্রশ্ন করবেন                                |
| ------------------------ | ---------------------- | ---------------------------------------------- |
| **Overlapping**          | Balance চলছে           | প্রাইস কি গতকালের রেঞ্জের ভেতরে ঘুরছে?         |
| **উপরে, ওভারল্যাপ নেই**  | Value উপরে গৃহীত       | পুলব্যাকে প্রাইস কি গতকালের VAH এর উপরে টিকছে? |
| **নিচে, ওভারল্যাপ নেই**  | Value নিচে গৃহীত       | বাউন্সে প্রাইস কি গতকালের VAL এর নিচে থাকছে?   |

"সম্পূর্ণ উপরে" হলো কঠোর পরীক্ষা। Value আংশিক ওভারল্যাপ করলে তাকে Overlapping বলুন, আর ইঙ্গিতের জন্য POC এর দিক দেখুন (যেমন মঙ্গলবার)।

## আগের দিনের লেভেল ব্যবহার

| লেভেল              | সম্ভাব্য ব্যবহার                                       | সতর্কতা                                            |
| ------------------ | ------------------------------------------------------ | -------------------------------------------------- |
| **আগের POC**       | ন্যায্য দামের রেফারেন্স; ট্রেন্ডে পুলব্যাক টার্গেট     | প্রাইস প্রায়ই এটা উপেক্ষা করে                     |
| **আগের VAH**       | Value উপরে সরার পর: Support হিসেবে নজরে রাখার লেভেল    | গতকালের Value এর ভেতরে ফিরে Close হলে ধারণা দুর্বল |
| **আগের VAL**       | Value নিচে সরার পর: Resistance হিসেবে নজরে রাখার লেভেল | উপরে ফিরে Close হলে ধারণা দুর্বল                   |
| **দিনের High/Low** | রেঞ্জের চরম                                            | এগুলো ভাঙে                                         |

### উদাহরণ (চার্ট ছাড়া) — Value উপরে সরার পর

বুধবারের Value Area 1.0864 – 1.0874। বৃহস্পতিবার এর উপরে খুলে **1.0874** এ (বুধবারের VAH) পুলব্যাক করে। পরিকল্পনা: **1.0875** এ Hold এ Buy, Stop **1.0869** (বুধবারের POC এলাকার ঠিক নিচে), টার্গেট **1.0886**: রিস্ক ৬ পিপ, রিওয়ার্ড ১১, পরিকল্পিত **১ : ১.৮**। প্রাইস বুধবারের Value Area এর ভেতরে ফিরে Close করলে "উপরে গৃহীত" ধারণা দুর্বল ধরে বেরিয়ে যান।

## সাধারণ ভুল

| ভুল                                    | সমাধান                                                     |
| -------------------------------------- | ---------------------------------------------------------- |
| প্রতিটি উঁচু POC কে "Accumulation" বলা | মুভ বর্ণনা করুন; কে করছে তা অনুমান করবেন না                |
| একদিনের Migration কে সংকেত ধরা         | কয়েকদিন ও আশপাশের স্ট্রাকচার দেখুন                        |
| আগের VAH/VAL কে দেয়াল ধরা             | এগুলো রেফারেন্স; Stop রাখুন                                |
| দিনের সংজ্ঞা প্রতিদিন বদলানো           | একটি সেশন সংজ্ঞা রাখুন                                     |
| Overlapping দিন উপেক্ষা                | ওভারল্যাপ প্রায়ই Balance — জোর করে ট্রেন্ড ট্রেড করবেন না |

## অনুশীলন

1. দশ দিনের প্রতিদিনের POC, VAH ও VAL লিখে Migration শ্রেণিবদ্ধ করুন: Overlapping, উপরে, বা নিচে।
2. "ওভারল্যাপ নেই" দিনের পর পরদিন আগের VAH বা VAL এ প্রাইস কী করেছে লিখুন।
3. কতবার মুভ চলেছে আর কতবার পুরোনো Value Area এর ভেতরে ফিরেছে গুনুন। হিসাব রাখুন।
4. আপনার [ট্রেডিং জার্নালে](/bn/tools/journal-template) লিখুন।
